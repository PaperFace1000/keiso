# 🔤 文字

## 🖋️ フォント

| 役割 | 変数 | 指定 |
|---|---|---|
| 本文 | `--font-sans` | `"Hiragino Sans", "Noto Sans JP", "Yu Gothic UI", sans-serif` |
| 等幅（ラベル・数字・コード・キー） | `--font-mono` | `ui-monospace, "SF Mono", "Cascadia Mono", "JetBrains Mono", Menlo, monospace` |
| ドットの数字 | `--font-dot` | `"Doto", var(--font-mono)` |

### 📖 本文と等幅

- 本文は OS のゴシック体を名前で指すだけにする。Web フォントを読み込まない（外部の CDN に頼らない。表示が速く、通信のない環境でも同じに見える）
- 等幅も OS のものを使う。ラベル・表の見出し・数字・コード・キーの表示に使う

### ⠿ ドットの数字（Doto）

- Doto は点で描く等幅のフォント（SIL Open Font License 1.1）。太さ（`wght` 100〜900）と点の丸さ（`ROND` 0〜100）を変えられる
- **使うのは英数字の主役の数字・時刻・件数だけ**（`.k-dot`）。見出しや本文、日本語には使わない（日本語の字形を持たず、長い文は読みにくい）
- 指定は太さ 700、`font-variation-settings: "ROND" 100`（丸い点）、字間 `0.04em`、`font-variant-numeric: tabular-nums`、行間 1
- 小さすぎると点が潰れる。**24px 以上**で使う。それより小さい数字は等幅（`.k-num`）にする
- フォントは英数字と記号だけに絞った `fonts/doto-latin.woff2`（約 5.5KB）を同梱して配る。CDN から読まない
- 見本の HTML はファイルを直接開いても表示できるよう、`samples/assets/fonts.css` に base64 で埋め込んである（`tools/build.py` が作る）
- 絞り直すとき・版を上げるときの手順は `docs/licenses.md` の「Doto を更新する」

## 📐 大きさと行間

| 用途 | 大きさ | ほか |
|---|---|---|
| 本文 | 15px | 行間 1.7（`body` に指定） |
| 章の見出し（`.k-heading h2`） | 18px | 太さ 700 |
| 欄・ダイアログ・空の表示の見出し | 16px | |
| ロゴ | 16px | 等幅、太さ 700、字間 `0.2em`、大文字 |
| ボタン・トースト・一覧の行・表・値の一覧・知らせの本文 | 14px | 小さいボタンは 13px |
| 入力欄のラベル | 13px | 太さ 500 |
| 補足・日時・エラー・目盛りの値・件数 | 12px | 件数は等幅・太さ 600 |
| ラベル・タグ・状態の印・表の見出し・キー | 11px | 等幅・大文字（下の「ラベル」） |
| 画面の主役の数字（`.k-stat__value`） | 44px | ドットの数字。単位は 13px の等幅で横に添える |

- 見出しは `text-wrap: balance`、行間 1.4
- 本文の中で太字を多用しない

## 🏷️ ラベル

小さな英字の見出し（`.k-label`）。欄の名前・表の見出し・状態の名前に使い、本文と役割を分ける。

- 等幅、11px、太さ 500、**大文字**（`text-transform: uppercase`）、字間 **`0.14em`**、色は `muted`
- 書くのは英語の短い名前（`STATUS`・`UPDATED`・`TOTAL`）。日本語のラベルが要るところでは、ラベルを使わず 13px の普通の文字にする
- 状態や区分を囲むときは角括弧を付ける（`.k-bracket` → `[ ALERT ]`）。括弧と文字の間は改行しない空白
- ナビ・タブ・区切りの選択の文字は 12px、字間 `0.1〜0.12em` の等幅・大文字にする

## 🔢 数字と日時

- 数字が縦に並ぶところ（表の数値の列・件数・時間）は等幅の数字（`font-variant-numeric: tabular-nums`）にし、表では右に寄せる
- 日時は `2026-10-01 15:23` の形にそろえる。秒が要るときだけ `15:23:08`
- 結論の数字には、単位・対象の期間・比べる相手（前の月との差など）を必ず添える
