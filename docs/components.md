# 🧩 部品の決まり

見本は `samples/ui-kit.html`。見本の CSS は `samples/assets/kit.css`（クラス名は `k-` で始まる）。アプリへはこの CSS を配らず、ここの決まりと見本の見た目に合わせて各アプリで作る。色は `var(--color-*)` だけを使う。

共通の値:

| 名前 | 値 | 使いどころ |
|---|---|---|
| 線 | 1px | 枠・区切り |
| 角（箱） | 6px（`--radius`） | 欄・カード・知らせ・トースト・ダイアログ・表の枠・数字の欄・空の表示・四隅の鉤 |
| 角（小） | 4px（`--radius-sm`） | ボタン・入力欄・プロンプト・切り替え・区切りの選択・タグ、箱の中で反転させる行。16px 前後の四角（チェックボックス・キー・件数）は 2〜3px |
| 帯 | 2px | 状態の欄の左の帯、今いるページ・タブの下線 |
| 高さ | 36px（小 28px） | ボタン・入力欄 |
| 動き | `cubic-bezier(.2, 0, 0, 1)`、0.1〜0.15 秒 | 色の変化、つまみの移動 |

## 🔘 ボタン

| 種類 | 見た目 | 使いどころ |
|---|---|---|
| 主（`.k-btn--primary`） | **反転**: 地が `text`、文字が `base` | その画面で一番の操作（保存・作成）。**1 画面に 1 つ** |
| 普通（既定） | 地なし + `border-strong` の枠 | 並べる操作、キャンセル |
| 括弧（`.k-btn--ghost`） | 地も枠もなし。文字を等幅の角括弧 `[ 取り消す ]` で囲む。なぞると `sunken` と括弧が文字の色になる | 取り消す・戻るなどの補助の操作、行の中の操作 |
| ALERT（`.k-btn--alert`） | 地が `alert`、文字が `on-alert` | 削除など取り消せない操作の確定 |

- 高さ 36px 以上、左右の余白 16px、文字 14px・太さ 500。小さいもの（`.k-btn--sm`）は高さ 28px・13px
- 主と ALERT のボタンは、なぞると内側に地の色の 2px の線を出す（色は変えない）
- アイコンと文字の間は 8px。アイコンだけのボタン（`.k-btn--icon`）は正方形にし、`aria-label` を必ず付ける
- 文字だけのボタンを、括弧も枠も無い素の文字にしない（押せるものだと分からないため）。枠を付けないアイコンだけのボタン（閉じるなど）は、アイコンがあるので括弧を付けない
- 押せないときは、種類に関係なく塗りをやめ、**左下から右上への斜線 1 本**（`--color-border`、太さ 1px。濃くすると文字より目立つので枠線より淡くする）・点線の枠・`muted` の文字・`cursor: not-allowed` にする。透明度を下げるだけにしない（押せるボタンが薄く見えているだけと区別できないため）。押せない理由は近くに文で書く
- 送信中は `aria-busy="true"` を付けて押せなくし、文字の前に点滅する四角いカーソルを出す（二重送信の防止は `docs/patterns.md`）
- 文言は折り返さない。幅が足りなければボタンの並びを次の行に回す

## ✏️ 入力欄

- ラベル 13px・太さ 500、欄との間は 4px。説明（`.k-field__hint`）は 12px の `muted`
- 欄は高さ 36px 以上、余白 6px 12px、文字 15px、地は `surface`、枠は `border-strong`
- フォーカス中は `focus`（本文の色）の 2px の輪を欄に重ねて出し、吸い付きと点滅の動きを付ける（`docs/accessibility.md`）。誤りのある欄の赤い枠とは色で見分けられる
- エラーのときは `aria-invalid="true"` を付け、枠を `alert` にし、左に 2px の帯を出す。下に 12px の ALERT の文字（アイコン付き）を出す
- プレースホルダーは `muted`。ラベルの代わりにしない
- 複数行（`.k-textarea`）は最小 96px で、縦にだけ広げられる
- セレクト（`.k-select`）は OS の見た目を消し、右に小さな下向きの三角を描く

### プロンプト（`.k-prompt`）

- 検索やコマンドを打つ欄。先頭に等幅の `>` を `accent-strong` で出し、文字は等幅にする
- フォーカスは欄の外側の輪で示す（中の `input` には輪を出さない）
- 1 画面に 1 つまで。普通の入力欄の代わりには使わない

## ☑️ チェックボックス・ラジオボタン

- チェックボックスは 16px の**四角**、ラジオボタンは 14px の四角を 45 度回した**ひし形**
- 選んだ印は中に塗りの四角（チェックボックス 8px・ラジオ 6px、色は `text`）。チェックの線は描かない
- ラベルと印の間は 8px、文字は 14px。ラベル全体を押せるようにする
- 押せないときは印を `opacity: .45`

## 🎚️ 切り替え（`.k-switch`）

- 40×20px の四角い枠に、12px の四角いつまみ
- 入のときは枠を反転（地が `text`）し、つまみを右へ動かして `base` の色にする
- 横に等幅 11px で `ON` / `OFF` を出す（`.k-switch__state`）。色とつまみの位置だけで状態を伝えない
- 押すとすぐ効く設定にだけ使う。保存ボタンを押すまで効かない欄にはチェックボックスを使う

## 🎛️ 区切りの選択（`.k-segment`）

- 2〜5 個の選択肢を枠の中に並べる。文字は等幅 12px・大文字、字間 `0.1em`
- 選んでいるものは反転し、`aria-pressed="true"` を付ける
- 表示の切り替え（テーマ・期間・並べ方）に使う。フォームの値の入力には使わない

## 🏷️ タグ（`.k-tag`）

- 高さ 22px、左右 8px、等幅 11px・大文字、1px の枠
- 分類の色を付けるときは `data-extra-color` を付ける（`--extra-text`・`--extra-bg`・`--extra-border` で塗る）。色が無いときは枠が `border-strong`、地なし
- 中に入れるのは短い英字か短い日本語。長い文言はタグにしない

## 🚦 状態の印（`.k-status`）

- 7px の四角い点 + 等幅 11px・大文字の名前（字間 `0.14em`）。色は親の `.k-role-*` で決まる
- **名前を必ず書く**（`SUCCESS`・`INFO`・`WARNING`・`ALERT`）。点だけで状態を伝えない
- 動いている最中のもの（同期中・録音中）は `.k-status--live` で点を点滅させる。`prefers-reduced-motion` では止まる
- 件数（`.k-count`）は反転の小さな札（等幅 12px・太さ 600）

## 📢 知らせの欄（`.k-notice`）

- 左に 2px の帯（役割の色）、地は `-bg`、枠は `-border`
- 中は 3 列: 線のアイコン（役割の色）・題と本文・閉じるボタン（必要なときだけ）
- 題は等幅 11px・大文字の英字（`[ ALERT ]` のように角括弧を付けてもよい）。本文は 14px の日本語で、何が起きたか・どうすればいいかを書く
- ALERT の欄には `role="alert"`、それ以外は `role="status"`
- 失敗はその場所に出し、すでに出ている中身は消さない

## 🍞 トースト（`.k-toast`）

- 画面の下に出る短い知らせ。**反転**（地が `text`、文字が `base`）、左右 16px、14px の文字、浮いているので影を付ける
- 中は状態の印・本文・操作（`元に戻す` など。等幅 12px・下線）
- 4〜6 秒で消す。操作が付いているものは、なぞっている間は消さない
- 失敗はトーストで済ませず、知らせの欄でその場所に出す

## 📋 一覧の行（`.k-row`）

- 高さ 44px 以上、余白 10px 12px、行と行の間は 1px の `border`。なぞると地を `sunken`
- 題 14px・太さ 500（はみ出たら省略記号）、補足 12px の `muted`
- **選んでいる行・今開いている行は反転**し（`aria-selected="true"` か `aria-current="true"`）、行の先頭に等幅の `▸` を出す。補足の文字は反転の色を `opacity: .75` で薄め、状態の印も反転の文字の色にする
- `▸` の幅（1 文字分）は選んでいない行でも空けておく。選んだときに行の中身が横にずれないようにするため
- 反転した行の中のキー（`kbd`）と件数（`.k-count`）は、地を塗らずに反転の文字の色の線と文字だけにする。地を塗ったままだと、反転の文字の色と重なって読めなくなる。行の中に地を塗った部品を足すときは、反転したときの色も必ず決めること

## 🧾 表（`.k-table`）

- 外枠ごと横にスクロールできる箱（`.k-table-wrap`）に入れる。画面の幅を超えても本文を横に動かさない
- 見出しの行は等幅 11px・大文字・`muted`、地は `surface`、下に `border-strong` の線
- 本文の行は 14px、余白 10px 12px、行の間は `border`。なぞると `sunken`
- 数値の列（`.is-num`）は右寄せ・等幅の数字

## 🗂️ 値の一覧（`.k-kv`）

- 見出しと値の 2 列（見出しの列は中身の幅、間は 8px 24px）
- 見出しは等幅 11px・大文字・`muted`、値は 14px。長い値は `overflow-wrap: anywhere` で折り返す

## 🔢 数字の欄（`.k-stat`）

- 画面の主役の数字。ドットの数字（`.k-dot`）で 44px、単位は 13px の等幅で横に添える
- 上にラベル（何の数字か）、下に比べる相手との差（`.k-stat__delta`、12px の等幅。良し悪しがあるときは `.k-role-*` で色を付け、`+` `−` の記号も付ける）
- 地は `surface`、枠は `border`、余白 16px

## 📶 目盛り（`.k-meter`）

- 6px の目盛りを 2px 空けて並べた帯（高さ 8px）。満たした分を `--k-role`（無ければ `text`）で塗る
- 右に必ず数字（`72%`、等幅 12px）を出す。帯の長さだけで量を伝えない
- 進み具合・使っている量に使う。グラフの代わりにしない

## ⏳ 読み込み中（`.k-loader`）

- 5px の四角い点を 4 つ並べ、左から順に灯す
- 文字（`読み込み中`）を横に添えるか、`aria-label` を付ける
- 0.5 秒以内に終わるものには出さない（ちらつくため）

## 🫙 空の表示（`.k-empty`）

- 点線の枠の中に、ソリッドのアイコン（48px）・見出し（16px）・1 文の説明・次の操作のボタンを縦に並べる
- 何も無い理由と、何をすれば中身ができるか（作る・取り込む・絞り込みを外す）を書く
- 絞り込みの結果が 0 件のときは、絞り込みを外すボタンを出す

## ⌨️ キー（`kbd`）

- 等幅 11px、1px の枠で下だけ 2px、地は `surface`。最小の幅は 1.8 文字
- キーボードの操作の説明に使う（`Ctrl` + `K`）

## 📐 枠と区切り

- **欄**（`.k-panel`）: 地 `surface`、枠 `border`、余白 16px
- **四隅の鉤**（`.k-frame`）: 左上と右下に 10px の鉤（`border-strong`）。ページに 1〜2 か所、目立たせたい欄にだけ
- **区切り線**（`.k-rule`）: 1px の線の真ん中に 5px の四角（`border-strong`）。節の区切りに使う。普通の区切りは 1px の線だけにする
- **章の見出し**（`.k-heading`）: 見出し 18px の下に 1px の線。右端にラベル（件数・更新日時）を置いてよい
