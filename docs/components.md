# 🧩 部品の決まり

見本は `samples/ui-kit.html`（基本の部品）と `samples/inputs.html`・`samples/overlays.html`・`samples/records.html`・`samples/time.html`（選ぶ部品・浮かぶ部品・欄と一覧・日付と時刻）。見本の CSS は `samples/assets/kit.css`（クラス名は `k-` で始まる）。アプリへはこの CSS を配らず、ここの決まりと見本の見た目に合わせて各アプリで作る。色は `var(--color-*)` だけを使う。

共通の値:

| 名前 | 値 | 使いどころ |
|---|---|---|
| 線 | 1px | 枠・区切り |
| 角（箱） | 6px（`--radius`） | 欄・カード・知らせ・トースト・ダイアログ・表の枠・数字の欄・空の表示・四隅の鉤 |
| 角（小） | 4px（`--radius-sm`） | ボタン・入力欄・プロンプト・切り替え・区切りの選択・タグ、箱の中で反転させる行。16px 前後の四角（チェックボックス・キー・件数）は 2〜3px |
| 帯 | 2px | 状態の欄の左の帯、今いるページ・タブの下線 |
| 高さ | 36px（小 28px） | ボタン・入力欄 |
| 動き | `cubic-bezier(.2, 0, 0, 1)`、0.1〜0.15 秒 | 色の変化、つまみの移動 |
| 影 | `0 8px 24px -12px rgba(0, 0, 0, .5)`（`--shadow-float`） | **浮かぶものだけ**: トースト・画面の上の知らせ・メニュー・ポップオーバー。欄・カード・ダイアログには付けない |

- 選んだもの・今指しているものは、どの部品でも**反転**（地が `text`、文字が `base`）で示す。枠の色を変える・輪を足すだけで選んだことを示さない
- 印は四角い点・ひし形・四角で描く。丸い札（角 999px）は使わない
- 動きは段階的（`steps()`）にする。なめらかに回るスピナーは使わず、順に灯る点（`.k-loader`）か点滅する四角いカーソルにする

## 🔘 ボタン

| 種類 | 見た目 | 使いどころ |
|---|---|---|
| 主（`.k-btn--primary`） | **反転**: 地が `text`、文字が `base` | その画面で一番の操作（保存・作成）。**1 画面に 1 つ** |
| 普通（既定） | 地なし + `border-strong` の枠 | 並べる操作、キャンセル |
| 括弧（`.k-btn--ghost`） | 地も枠もなし。文字を等幅の角括弧 `[ 取り消す ]` で囲む。なぞると `sunken` と括弧が文字の色になる | 取り消す・戻るなどの補助の操作、行の中の操作 |
| ALERT（`.k-btn--alert`） | 地が `alert`、文字が `on-alert` | 削除など取り消せない操作の確定 |

- 高さ 36px 以上、左右の余白 16px、文字 14px・太さ 500。小さいもの（`.k-btn--sm`）は高さ 28px・13px
- 主と ALERT のボタンは、なぞると内側に地の色の 2px の線を出す（色は変えない）
- アイコンと文字の間は 8px。アイコンだけのボタン（`.k-btn--icon`）は正方形にし、`aria-label` を必ず付ける
- 文字だけのボタンを、括弧も枠も無い素の文字にしない（押せるものだと分からないため）。枠を付けないアイコンだけのボタン（閉じるなど）は、アイコンがあるので括弧を付けない
- 押せないときは、種類に関係なく塗りをやめ、**左下から右上への斜線 1 本**（`--color-border`、太さ 1px。濃くすると文字より目立つので枠線より淡くする）・点線の枠・`muted` の文字・`cursor: not-allowed` にする。透明度を下げるだけにしない（押せるボタンが薄く見えているだけと区別できないため）。押せない理由は近くに文で書く
- 送信中は `aria-busy="true"` を付けて押せなくし、文字の前に点滅する四角いカーソルを出す（二重送信の防止は `docs/patterns.md`）
- 文言は折り返さない。幅が足りなければボタンの並びを次の行に回す
- どの種類にも小さい版（`.k-btn--sm`）がある。行の中・ポップオーバーの中・入力欄の横など、36px では大きい所に使う
- 横いっぱいの版（`.k-btn--block`）は、ログインの画面のように 1 つしか操作の無い狭い箱でだけ使う
- 括弧のボタンの処理中は、括弧を残して `[` の右にカーソルを点滅させる（括弧を消すと押せるものに見えなくなるため）

### 文言が変わっても幅が変わらないボタン（`.k-steady`）

「開始」⇔「実行中」のように状態で文言が変わるボタンは、どの文言のときも同じ幅にする。幅が変わると、隣のボタンが押すたびに左右へずれ、押そうとした所に別のものが来る。

- ボタンの中に**すべての文言を同じマスに重ねて置き**（`display: inline-grid` の子をすべて `grid-area: 1 / 1`）、今の文言以外を `visibility: hidden` にする。幅は一番長い文言で決まる。`min-width` の固定値は、文字の大きさや書体が変わると合わなくなるので使わない
- 隠した文言には `aria-hidden="true"` も付け、今の文言と一緒に入れ替える
- アイコンも替えるときは同じ大きさのもの（`play` ⇔ `hourglass`）にする
- 押せない状態（「実行中」）は `disabled` にし、文言を「〜中」にして押せない理由が分かるようにする。フォーカスは次に押せるボタン（「止める」）へ移す
- 文言の長さが倍以上違うときは、短い方が間延びする。文言を近づけるか、アイコンだけのボタンと `aria-label` にする

### 押すたびに文言とアイコンが入れ替わる切り替え（`.k-btn--quiet`）

表示の密度などを 2 つの状態で行き来する操作。括弧の小さいボタンにする。

- 文言は**押すとどうなるか**を書く（「補足を隠す」⇔「補足を出す」）。アイコンも次の状態を表すもの（`eye-slash` ⇔ `eye`）にする
- 文字は `muted` にして主な操作より目立たせず、なぞると `text`。`title` に詳しい説明を入れ、文言と一緒に入れ替える
- `aria-pressed` は付けない（文言が状態を言うので、押した・押していないの読み上げと食い違う）。入と切を保つ設定は、押してすぐ効くならスイッチ、保存のボタンで送るならチェックボックス
- 切り替えても意味のない幅（899px 以下で本文の幅を変えるなど）では出さない

## ✏️ 入力欄

- ラベル 13px・太さ 500、欄との間は 4px。説明（`.k-field__hint`）は 12px の `muted`
- 欄は高さ 36px 以上、余白 6px 12px、文字 15px、地は `surface`、枠は `border-strong`
- フォーカス中は `focus`（本文の色）の 2px の輪を欄に重ねて出し、吸い付きと点滅の動きを付ける（`docs/accessibility.md`）。誤りのある欄の赤い枠とは色で見分けられる
- エラーのときは `aria-invalid="true"` を付け、枠を `alert` にし、左に 2px の帯を出す。下に 12px の ALERT の文字（アイコン付き）を出す
- プレースホルダーは `muted`。ラベルの代わりにしない
- 複数行（`.k-textarea`）は最小 96px で、縦にだけ広げられる
- セレクト（`.k-select`）は OS の見た目を消し、右に小さな下向きの三角を描く。選択肢の中に押せない項目・長い文言・補足が要るときは、下の「セレクト（独自）」にする

### 入力欄の横のボタン（`.k-field__row`）

- 入力欄とボタンを横に並べ、高さを 36px でそろえる（小さいボタンを下端に寄せない）。入力欄が残りの幅を取り（`flex: 1 1 12rem`）、狭いとボタンを次の行に回す
- ボタンは普通のボタン（主のボタンにしない。主はフォームの送信に残す）。結果は欄の説明の位置に `aria-live="polite"` で出す

### プロンプト（`.k-prompt`）

- 検索やコマンドを打つ欄。先頭に等幅の `>` を `accent-strong` で出し、文字は等幅にする
- フォーカスは欄の外側の輪で示す（中の `input` には輪を出さない）
- 1 画面に 1 つまで。普通の入力欄の代わりには使わない

## ☑️ チェックボックス・ラジオボタン

- チェックボックスは 16px の**四角**、ラジオボタンは 14px の四角を 45 度回した**ひし形**
- 選んだ印は中に塗りの四角（チェックボックス 8px・ラジオ 6px、色は `text`）。チェックの線は描かない
- ラベルと印の間は 8px、文字は 14px。ラベル全体を押せるようにする
- 押せないときは印を `opacity: .45`

## 🎚️ 切り替え（`.k-switch`）

- 40×20px の四角い枠に、12px の四角いつまみ
- 入のときは枠を反転（地が `text`）し、つまみを右へ動かして `base` の色にする
- 横に等幅 11px で `ON` / `OFF` を出す（`.k-switch__state`）。色とつまみの位置だけで状態を伝えない
- 押すとすぐ効く設定にだけ使う。保存ボタンを押すまで効かない欄にはチェックボックスを使う
- **押せないとき**は枠を点線、地を透明、つまみを `border-strong`（入のときは `muted`）、文言を `muted` にし、`cursor: not-allowed`。`ON` / `OFF` の文字は残す。透明度で薄めない。押せない理由を近くに文で書き、`aria-describedby` で結ぶ

## 🎛️ 区切りの選択（`.k-segment`）

- 2〜5 個の選択肢を枠の中に並べる。文字は等幅 12px・大文字、字間 `0.1em`
- 選んでいるものは反転し、`aria-pressed="true"` を付ける
- 表示の切り替え（テーマ・期間・並べ方）に使う。フォームの値の入力には使わない（フォームの値は下の選択肢のボタン）

## 🏷️ タグ（`.k-tag`）

- 高さ 22px、左右 8px、等幅 11px・大文字、1px の枠
- 分類の色を付けるときは `data-extra-color` を付ける（`--extra-text`・`--extra-bg`・`--extra-border` で塗る）。色が無いときは枠が `border-strong`、地なし
- 中に入れるのは短い英字か短い日本語。長い文言はタグにしない

## 🚦 状態の印（`.k-status`）

- 7px の四角い点 + 等幅 11px・大文字の名前（字間 `0.14em`）。色は親の `.k-role-*` で決まる
- **名前を必ず書く**（`SUCCESS`・`INFO`・`WARNING`・`ALERT`）。点だけで状態を伝えない
- 動いている最中のもの（同期中・録音中）は `.k-status--live` で点を点滅させる。`prefers-reduced-motion` では止まる
- 件数（`.k-count`）は反転の小さな札（等幅 12px・太さ 600）

## 🔖 印の使い分け（状態のバッジ・分類のバッジ・チップ）

| 部品 | 見た目 | 使いどころ |
|---|---|---|
| 状態の印（`.k-status`） | 四角い点 + 等幅 11px・大文字の名前。地なし | 行・表・ログの中の状態。いちばん軽い |
| 状態のバッジ（`.k-badge`） | `.k-status` に役割の `-bg` の地と `-border` の枠、高さ 22px、角 4px | カードの頭・詳細の見出しの横など、目を留めさせたい 1 か所だけ。行の中には使わない |
| タグ（`.k-tag`） | 枠つきの札、等幅 11px・大文字 | 短い英字の区分（`v2.4`・`DESIGN`） |
| 分類のバッジ（`.k-catbadge`） | 分類の色の地・枠・文字、12px、先頭に 7px の四角い点かアイコン 14px、最大 12em で省略 | 分類の名前（日本語でよい）。色の無い分類は `border` の枠と `muted` の文字 |
| チップ（`.k-chip`） | `border-strong` の枠、12px、最大 10em で省略、全文は `title` | 利用者が付けたタグ。1 行に並べ、入りきらない分は `+2`（`.k-chip--rest`、点線の枠・等幅） |
| 件数（`.k-count`） | 反転の小さな札 | 見出し・タブ・ボタンの横の数 |

- どれも角は 4px（件数は 3px）。丸い札にしない
- 状態の色（役割の色）は状態の印とバッジだけ、分類の色は分類のバッジとタグだけに使い、混ぜない
- `+2` には、まとめたものの名前を `title` に入れ、並び全体の `aria-label` に「ほか 2 個」まで書く

## 📢 知らせの欄（`.k-notice`）

- 左に 2px の帯（役割の色）、地は `-bg`、枠は `-border`
- 中は 3 列: 線のアイコン（役割の色）・題と本文・閉じるボタン（必要なときだけ）
- 題は等幅 11px・大文字の英字（`[ ALERT ]` のように角括弧を付けてもよい）。本文は 14px の日本語で、何が起きたか・どうすればいいかを書く
- ALERT の欄には `role="alert"`、それ以外は `role="status"`
- 失敗はその場所に出し、すでに出ている中身は消さない

## 🍞 トースト（`.k-toast`）

- 操作の結果を知らせる短い知らせ。**反転**（地が `text`、文字が `base`）、14px の文字、角 6px、浮いているので影（`--shadow-float`）を付ける
- 置き場所は右下（右と下から 16px、切り欠きの分を足す）。幅 `min(24rem, 100vw - 32px)`、599px 以下は左右 16px まで広げる。新しいものを下に、間 8px で積み、3 つを超えたら古いものから消す
- 入れ物（`.k-toasts`）は `aria-live="polite"` にして、画面に常に置いておく（後から足したトーストが読み上げられるように）

| 種類 | 印（ソリッド 20px） | 読み上げの頭 | 消えるまで |
|---|---|---|---|
| 成功 | `success`（✓ の円） | 「成功: 」 | 4 秒 |
| お知らせ | `info`（i の円） | 「お知らせ: 」 | 4 秒 |
| 注意 | `warning`（! のひし形） | 「注意: 」 | 4 秒 |

- 反転の地の上では役割の色が読めないので、種類は**印の形と読み上げの頭の言葉**で見分ける（頭の言葉は見えない文字）。色で塗り分けない
- 中は 3 列: 印・題（14px・太さ 600）と補足（13px、`opacity: .8` の 2 段目。何をすればいいか・何が残っているか）・右端の操作。操作は「元に戻す」（`Undo`、等幅 12px・大文字・下線）と閉じるボタン（括弧なしのアイコンだけの小さいボタン、`x`、`aria-label="このトーストを閉じる"`、なぞると細い枠）
- 操作の付いたものは 8 秒。**なぞっている間と、中にフォーカスがある間は消さない**（離れたら残りの時間から数え直す）
- 出るときは下から 2 段で、消えるときは 2 段で薄くする（`steps(2)`）。`prefers-reduced-motion` では動かさない
- **失敗はトーストにしない**。読み落とすと気付けないので、その場所の ALERT の知らせの欄で出す（`docs/patterns.md` の「知らせの出し方」）
- トーストの中だけに操作を置かない。「元に戻す」は、ごみ箱の一覧など別の場所からも同じことができるようにする

## 📣 画面の上の知らせ（`.k-topnotice`）

利用者の操作なしに画面を書き直したこと（ほかの画面で変わったので一覧を読み直した、など）を伝えるだけの小さな帯。操作の結果はトーストで知らせる。

- 画面の上の中央（ヘッダーの下）に 1 つだけ出し、4 秒で消す。閉じるボタンを置かず、押せない（`pointer-events: none`）
- 地 `info-bg`、枠 `info-border`、文字 `info`、13px、余白 4px 12px、角 4px、先頭に線のアイコン 16px（読み直しなら `arrow-clockwise`）。浮いているので影（`--shadow-float`）
- 幅は文言に合わせ（`width: max-content`）、`100vw - 32px` を超えたら折り返す
- 入れ物（`.k-topnotice-region`）は `role="status"` で常に置いておき、文言を入れ替えて読み上げさせる。次の知らせが来たら前のものを置き換える

## 📋 一覧の行（`.k-row`）

- 高さ 44px 以上、余白 10px 12px、行と行の間は 1px の `border`。なぞると地を `sunken`
- 題 14px・太さ 500（はみ出たら省略記号）、補足 12px の `muted`
- **選んでいる行・今開いている行は反転**し（`aria-selected="true"` か `aria-current="true"`）、行の先頭に等幅の `▸` を出す。補足の文字は反転の色を `opacity: .75` で薄め、状態の印も反転の文字の色にする
- `▸` の幅（1 文字分）は選んでいない行でも空けておく。選んだときに行の中身が横にずれないようにするため
- 反転した行の中のキー（`kbd`）と件数（`.k-count`）は、地を塗らずに反転の文字の色の線と文字だけにする。地を塗ったままだと、反転の文字の色と重なって読めなくなる。行の中に地を塗った部品を足すときは、反転したときの色も必ず決めること

## 🧾 表（`.k-table`）

- 外枠ごと横にスクロールできる箱（`.k-table-wrap`）に入れる。画面の幅を超えても本文を横に動かさない
- 見出しの行は等幅 11px・大文字・`muted`、地は `surface`、下に `border-strong` の線
- 本文の行は 14px、余白 10px 12px、行の間は `border`。なぞると `sunken`
- 数値の列（`.is-num`）は右寄せ・等幅の数字

## 🗂️ 値の一覧（`.k-kv`）

- 見出しと値の 2 列（見出しの列は中身の幅、間は 8px 24px）
- 見出しは等幅 11px・大文字・`muted`、値は 14px。長い値は `overflow-wrap: anywhere` で折り返す

## 🔢 数字の欄（`.k-stat`）

- 画面の主役の数字。ドットの数字（`.k-dot`）で 44px、単位は 13px の等幅で横に添える
- 上にラベル（何の数字か）、下に比べる相手との差（`.k-stat__delta`、12px の等幅。良し悪しがあるときは `.k-role-*` で色を付け、`+` `−` の記号も付ける）
- 地は `surface`、枠は `border`、余白 16px

## 📶 目盛り（`.k-meter`）

- 6px の目盛りを 2px 空けて並べた帯（高さ 8px）。満たした分を `--k-role`（無ければ `text`）で塗る
- 右に必ず数字（`72%`、等幅 12px）を出す。帯の長さだけで量を伝えない
- 進み具合・使っている量に使う。グラフの代わりにしない

## ⏳ 読み込み中（`.k-loader`）

- 5px の四角い点を 4 つ並べ、左から順に灯す
- 文字（`読み込み中`）を横に添えるか、`aria-label` を付ける
- 0.5 秒以内に終わるものには出さない（ちらつくため）

## 🫙 空の表示（`.k-empty`）

- 点線の枠の中に、ソリッドのアイコン（48px）・見出し（16px）・1 文の説明・次の操作のボタンを縦に並べる
- 何も無い理由と、何をすれば中身ができるか（作る・取り込む・絞り込みを外す）を書く
- 絞り込みの結果が 0 件のときは、絞り込みを外すボタンを出す

## ⌨️ キー（`kbd`）

- 等幅 11px、1px の枠で下だけ 2px、地は `surface`。最小の幅は 1.8 文字
- キーボードの操作の説明に使う（`Ctrl` + `K`）

## 📐 枠と区切り

- **欄**（`.k-panel`）: 地 `surface`、枠 `border`、余白 16px
- **四隅の鉤**（`.k-frame`）: 左上と右下に 10px の鉤（`border-strong`）。ページに 1〜2 か所、目立たせたい欄にだけ
- **区切り線**（`.k-rule`）: 1px の線の真ん中に 5px の四角（`border-strong`）。節の区切りに使う。普通の区切りは 1px の線だけにする
- **章の見出し**（`.k-heading`）: 見出し 18px の下に 1px の線。右端にラベル（件数・更新日時）を置いてよい

## 🍽️ メニュー・ポップオーバー（`.k-popover`・`.k-menu`）

押したボタンの下に浮かぶ箱。メニュー・フィルタ・選び手・状態の詳しい中身に使う。

- 地 `surface`、枠 `border-strong`、角 6px、影 `--shadow-float`（トーストと同じ値）、余白 12px（メニューは 4px）
- 幅は中身に合わせ、最小 12rem・最大 `min(22rem, 100vw - 32px)`。ボタンの左端にそろえて下に 4px 空けて開く。右端に置いたボタンは右端にそろえる（`.k-popover--end`）
- 画面の端からはみ出すときは、端から 8px 残して内側へずらす
- 閉じるのは、ボタンをもう一度押す・外側を押す・Esc。Esc で閉じたらボタンにフォーカスを戻す
- ボタンには `aria-expanded` と `aria-controls`。メニューは `aria-haspopup="menu"`、選び手などの箱は `role="dialog"` と `aria-label`

### 項目（`.k-option`）

メニュー・候補・選ぶダイアログの行で共通に使う。

- 高さ 36px 以上、余白 6px 12px 6px 8px、角 4px、14px。先頭に `▸` の幅（1 文字）を空け、アイコン 20px と文字の間は 8px
- **今指している行**（なぞった・キーボードで動かした）は反転し、先頭に `▸` を出す。キーボードで動かしている間は `▸` を点滅させる
- **選んである値**（`aria-checked="true"`・`aria-selected="true"`・`aria-current="true"`）は右端に 7px の四角い点を出す（チェックの線は描かない。チェックボックスの印と同じ考え方）
- 右端の補足（キー・件数）は等幅 12px の `muted`。反転した行では文字の色を `opacity: .75`
- 消す操作は `.k-option--alert`（`alert` の文字）。「なし」「戻る」は `.k-option--quiet`（`muted`）
- 区切りは 1px の `border` の線、まとまりの見出しは `.k-label`

### メニューのキー操作

| キー | 動き |
|---|---|
| Enter・Space・↓（ボタンで） | 開いて、選んである値か最初の項目にフォーカスを移す |
| ↑ ↓ | 項目を動く（端で反対の端へ回る） |
| Home・End | 最初・最後の項目 |
| Enter・Space | 選んで閉じ、ボタンに戻る |
| Esc | 閉じてボタンに戻る |
| Tab | 閉じて次へ移る |

- 役割は `role="menu"` と `role="menuitem"`。1 つを選ぶ並びは `role="menuitemradio"` と `aria-checked`
- 項目は `tabindex="-1"` にし、Tab では入らない

## 🔘 選択肢のボタン（`.k-choice`）

フォームの値を 2〜4 個から 1 つ選ぶ。表示の切り替え（`.k-segment`）とは別の部品にする。

| 選択肢 | 使う部品 |
|---|---|
| 2〜4 個で、短い文言かアイコンで表せる | 選択肢のボタン |
| 5 個以上、または文言が長い | ラジオボタンを縦に並べる |
| 多い | セレクト、段階的に絞る選択 |

- 中身は本物のラジオボタン（`fieldset` と `legend`、見えない `input type="radio"`）。矢印キーで選び直せ、読み上げで何個中の何個目か分かる
- 等しい幅で並べ（`repeat(auto-fit, minmax(min(100%, 7.5rem), 1fr))`、間 8px）、狭ければ折り返す
- 1 つは高さ 36px 以上、余白 6px 12px、角 4px、地 `surface`、枠 `border-strong`、14px。先頭にラジオボタンと同じひし形の印（9px）、アイコンは 16px
- 選んだものは**反転**し、ひし形を塗る。主のボタンと同じ反転だが、先頭のひし形と、横に並ぶ組であることで送信のボタンと見分ける
- フォーカスはボタン全体に輪を出す（`label:has(input:focus-visible)`）
- 押せない選択肢は点線の枠と `muted` の文字。理由を文言に入れる（「メール（未設定）」）

## 📌 押すたびに入と切が変わるボタン・行のピン

- `aria-pressed` を付けたボタンは、入（`true`）のとき**反転**する。切（`false`）の括弧のボタンは文字を `muted` にする
- 行を「よく使う作業」などに加える・外すピンは、行の右端の操作の並びに置く、アイコンだけの小さいボタン（28px、`star` 16px）
- `aria-label` と `title` は押すとどうなるかを、行の題名を入れて書く（「倉庫 A の棚卸しをよく使う作業に加える」⇔「…から外す」）。`aria-pressed` と一緒に切り替える
- 線とソリッドのアイコンを入れ替えて状態を示さない（1 つの欄に 2 種類のアイコンを混ぜないため）。状態は反転で示す
- 押したらすぐ見た目を変え、保存は裏で行う。失敗したら元に戻してトーストで知らせる
- サーバーには「切り替える」ではなく「加える」「外す」を送る（同じ要求が 2 回届いても結果が変わらない）
- 加えた先の一覧が同じ画面にあれば、どちらで変えても両方に反映する

## 📅 日付・時刻の入力

- ブラウザの素の欄（`type="date"`・`"time"`・`"datetime-local"`）を使い、入力欄（`.k-input`）と同じ高さ・枠・余白にする。日付を選ぶ独自のポップオーバーは作らない
- 値は等幅の数字（`font-family: var(--font-mono)`、`tabular-nums`）で左寄せ。iOS で中央に寄るのを `::-webkit-date-and-time-value { text-align: left; }`、Chrome の上下 1px の余白を `::-webkit-datetime-edit-fields-wrapper { padding: 0; }` で消す
- カレンダーのアイコンの色は、テーマの `color-scheme` に任せる（自分で塗らない）
- 開始と終了のように組になるものは 2 列（`.k-range`、間 12px）に並べ、599px 以下で 1 列にする。組全体に見出しを付ける（`role="group"` と `aria-labelledby`）
- 終了が開始より前などの誤りは、送る前に確かめ、終了の欄に `aria-invalid` と、組の下に理由と直し方を出す

## 🔽 セレクト（独自。`.k-picker-btn` + `.k-listbox`）

5 個以上から 1 つを選ぶ欄で、選択肢に押せない項目・長い文言・補足があるもの。素のセレクト（`.k-select`）で足りるならそちらを使う。

- **押すボタン**: 選ぶ欄のボタン（`.k-picker-btn`）。高さ 36px、選んだ値は 1 行で省略し、欄の幅を選択肢の長さで広げない（`.k-field` の列は `minmax(0, 1fr)`）。開いている間は枠を `text` にする
- **箱**（`.k-listbox`）: ポップオーバーと同じ地・枠・影、余白 4px。幅はボタンに合わせ、高さ 320px を超えたら箱の中だけスクロール
- **項目**は `.k-option`。指している行は反転して `▸`、選んである値は右端に四角い点。長い文言は折り返す
- **押せない項目**は `aria-disabled="true"` で文字を `muted`、`cursor: not-allowed`。指す行にしない（↑↓ で飛ばす）。押せない理由を文言に入れる（「22:00（夜間は送れません）」）
- **押せない欄**は枠を点線、地を透明、文字を `muted`、`cursor: not-allowed`。理由を欄の説明に書く

| キー | 動き |
|---|---|
| Enter・Space・↓・↑（ボタンで） | 開いて、選んである値（無ければ最初の項目）を指す |
| ↑ ↓ | 押せる項目を動く。端で止まる |
| Home・End | 最初・最後の押せる項目 |
| 文字 | その文字で始まる項目へ移る（続けて打った文字は 0.5 秒だけつなげる） |
| Enter・Space | 選んで閉じ、ボタンに戻る |
| Esc | 閉じてボタンに戻る |
| Tab | 閉じて次へ移る |

- 役割はボタンに `aria-haspopup="listbox"` と `aria-expanded`、箱に `role="listbox"`、項目に `role="option"` と `aria-selected`。フォーカスは箱に置き、`aria-activedescendant` で行を指す。指した行は見える位置まで送る
- ボタンの名前は `aria-labelledby` で欄の名前と今の値を続けて読ませる

## 🔎 探して選ぶ欄（Combobox）

対象が数十件あり、名前で絞ってから選ぶ欄。分類から選ぶほうが早いときは下の「段階的に絞る選択」。

- **押すボタン**: 選ぶ欄のボタン（36px）。先頭に対象のアイコン 16px。選んでいなければ「選んでいません」を `muted`、選んだ後は分類のバッジと名前（1 行で省略）。`aria-label` に欄の名前と今の値を入れる（「記録を付ける作業: 空調の点検」）
- **ポップオーバー**: 幅 `min(28rem, 100vw - 32px)`、余白 8px。上に小さいプロンプト（`.k-prompt--sm`）、下に一覧（高さ `min(24rem, 50vh)` まで）
- **一覧**: 「選ばない」（`.k-option--quiet`）→ `RECENT` → `ALL`。まとまりの見出しはスクロールしても上に残し、中身の無いまとまりは出さない。文字を入れたら `RESULTS` 1 つにまとめる。項目は 2 段（名前と分類のバッジ）
- **状態の文**（一覧の下、12px の `muted`、`aria-live="polite"`）: 件数・「探しています」（順に灯る点）・「見つかりません。言葉を短くしてください。」。失敗は `alert` の文字で `role="alert"`、何をすればいいかまで書く
- 打つたびに問い合わせず、300ms 待ってから探す。探している間は前の結果を `muted` の文字で残し、一覧に `aria-busy="true"`（一覧を消すと、指していた行と位置を見失う）
- キー: ↑↓ で行を動き（端で止まる）、Enter で選んで閉じ、Esc で閉じてボタンに戻り、Tab で閉じて次へ。フォーカスは探す欄に置いたまま `aria-activedescendant`（探す欄は `role="combobox"`、一覧は `role="listbox"`）。変換中のキーは選ぶ操作にしない（`isComposing`）

## 🏷️ タグで絞り込む（`.k-tagfilter`）・タグを付ける（`.k-tagpick`）

**タグで絞り込む**（いくつでも選べる札）

- 中身は本物のチェックボックス（`fieldset` と `legend`、見えない `input type="checkbox"`）。Tab と Space で選べる
- 札: 高さ 32px、余白 0 12px、13px、地 `surface`、枠 `border-strong`、角 4px。先頭にチェックボックスと同じ 9px の四角。間 8px で折り返す
- **選んだ札は反転**し、先頭の四角を塗る。選択肢のボタン（ひし形・1 つだけ）とは先頭の印で見分ける
- フォーカスは札全体に輪（`label:has(input:focus-visible)`）。絞り込んだ結果は `aria-live="polite"` で読み上げる。タグが 1 つも無いときは欄ごと出さない

**タグを付ける**

- 見出し 13px の先頭に `tag` 16px、上限を書く（「タグ（5 個まで）」）
- 付けたタグ: 高さ 32px、13px、地 `surface`、枠 `text`、角 4px。右に外すボタン（括弧なしのアイコンだけの小さいボタン 26px、`x` 14px、`aria-label="〇〇を外す"`）
- 外すボタンにフォーカスして Backspace・Delete でも外せる。←→ で隣のタグの外すボタンへ移る。外したらフォーカスを次のタグ（無ければ入力欄）へ移す
- 候補: 小さいボタン（`plus` 16px）。付けたものは候補から除く
- 新しい名前: 入力欄の横のボタン（`.k-field__row`）「足す」。入力欄の Enter でも足し、外側のフォームは送らない。変換中の Enter は無視する。空・重複は足さずに理由を説明の位置に出す
- 上限まで付けたら候補と入力欄を隠し、そのことを `aria-live="polite"` で読み上げる。付けたタグが無いときは並びの間を空けない

## 🪜 段階的に絞る選択（`.k-cascade`）

項目が多く、分類から選ぶほうが早い欄。押すボタン（`.k-picker-btn`、セレクトと同じ見た目）と、その下に開くポップオーバーで作る。

- **押すボタン**: 高さ 36px、先頭に対象のアイコン 16px、右に下向きの三角。選んでいなければ「選んでいません」を `muted`。選んだら分類のタグ（`.k-tag`）と名前を並べ、名前は 1 行で省略する
- **ポップオーバー**: 幅 `min(28rem, 100vw - 32px)`、余白 8px。上から次の順に置く
  1. 固定した項目（先頭に `star` 16px）。下に `border` の線
  2. すべてから探す欄（小さいプロンプト `.k-prompt--sm`）。文字を入れると、分類に関係なくすべての項目から探した結果に替え、件数か「見つかりません」を出す。その間は固定した項目を隠す
  3. 一覧: 「なし（選ばない）」→ `RECENT`（最近使った 5 件まで）→ `CATEGORIES`（分類の色の四角い点・名前・件数・`caret-right`）。高さは `min(24rem, 50vh)` までで、まとまりの見出しはスクロールしても上に残す
  4. 分類を開くと、その分類の項目だけにする。先頭に「分類の一覧」の行（`arrow-left`、`muted`）を置き、押すと戻る
- 項目の行は `.k-option`。今指している行は反転、選んである値は右端の四角い点

**キー操作**（フォーカスは探す欄に置いたまま、`aria-activedescendant` で行を指す。探す欄は `role="combobox"`、一覧は `role="listbox"`）

| キー | 動き |
|---|---|
| ↑ ↓ | 行を動く。端で止まる。一覧の先頭から ↑ で固定した項目へ上がる |
| Enter | 項目なら選んで閉じ、分類なら開き、「分類の一覧」なら戻る |
| → | 分類の行で、探す欄が空なら開く |
| ←・Backspace | 分類の中で、探す欄が空なら分類の一覧に戻り、戻った分類の行を指す |
| Esc | 閉じてボタンに戻る |
| Tab | 閉じて次へ移る（一覧にはフォーカスを入れない） |

- 開いたときは、選んである項目が見えていればそれを、無ければ最初の項目を指す
- 日本語の変換中のキーは変換の操作として扱い、選ぶ操作にしない（`isComposing`）
- 固定した項目と最近使った項目は利用者ごとに覚える。固定するかどうかは項目のメニューで選ぶ

## 🎨 色の選び手・アイコンの選び手

分類の色と線のアイコンから 1 つを選ぶ。押すボタンとポップオーバー（`role="dialog"`）で作り、選ぶと閉じる。

- **押すボタン**（`.k-swatch-btn`）: 高さ 36px、地 `surface`、枠 `border-strong`、角 4px。今の色の見本か今のアイコンと、名前、`caret-down`。`aria-label` に対象と今の値を入れる（「棚の色: 青」）
- **色の見本**（`.k-swatch`）: 20px の四角、角 2px、`data-extra-color` で `--extra-bg` の地・`--extra-border` の枠、真ん中に `--extra-text` の 8px の四角い点
- **色なし**: 点線の枠（`border-strong`）だけの見本と「色なし」の文字を、マスの並びの上に横長の行で置く。斜線は押せないボタンの印なので、色なしには使わない
- **マス**（`.k-cell`）: 32px の四角、角 4px、間 4px。色は 6 列 × 2 行（`tokens/extra-colors.json` の並びのまま）。なぞると枠を `border-strong`
- **選んでいるマス**は `aria-pressed="true"` で反転する。色のマスは見本の中の地と点の色を入れ替える（地が `--extra-text`、点が `--extra-bg`。比は分類の色の文字と地の組と同じなので 4.5 以上）
- マスの名前（色の名前・アイコンの名前）は `aria-label` と `title` に入れる
- **アイコンの並び**: 幅 `min(19rem, 100vw - 64px)`、高さ `min(16rem, 45vh)` まで。上に絞り込みの欄（名前で、全角・半角と大文字・小文字の違いを無視する）、その下に「なし」の横長の行。1 つも合わなければ「見つかりません」を `aria-live="polite"` で出す
- キー操作: 開いたら選んであるマス（アイコンは絞り込みの欄）にフォーカス。矢印キーでマスを上下左右に動き、Enter・Space で選んで閉じ、Esc で閉じてボタンに戻る

## 📂 開け閉めする欄（`.k-disclosure`）

本文の一部を折りたたむ。見出し（`h3` など）の中にボタンを置き、`aria-expanded` と `aria-controls` で中身と結び付ける。中身は `hidden` で隠す。

| 種類 | 見た目 | 使いどころ |
|---|---|---|
| 枠つき（既定） | 枠 `border`、角 6px、地 `surface`、頭は 14px・太さ 600 | 前回の記録など、中身が主役のもの |
| 枠なし（`--quiet`） | 枠なし、頭は 13px の `muted`、幅は文字に合わせる | 本文に添える補足（詳しい情報など） |

- 頭は高さ 36px 以上（枠なしは 28px）、余白 6px 12px。左に `caret-right` 16px（`muted`）を置き、開くと 90 度回して下を向ける（2 段の `steps()` で、なめらかに回さない）
- 頭の右端に件数や日付を添えるときは等幅 12px の `muted`
- 中身は余白 4px 12px 12px、左は矢印の分だけ字下げして見出しの文字にそろえる。14px
- 並べるときは間 8px。フォーカスの輪は、枠つきは内側（`outline-offset: -2px`）、枠なしは外側
- 開け閉めの状態は保存しない

## 🗃️ 欄（`.k-section`）

ダッシュボードなどで、中身ごとにまとめた枠。欄（`.k-panel`）の中に、章の見出し（`.k-heading`）と同じ作りの頭を置く。

- 頭: 線のアイコン（20px、`muted`）・見出し 16px・件数（`.k-count`）・右端に更新の時刻（等幅 12px の `muted`、「3 分前に更新」）。下に 1px の `border` の線
- 同じ画面の欄は、全部にアイコンを付けるか、どれにも付けないかにそろえる
- 欄の中の行は地を `base` にして、欄の `surface` と差を付ける

| 状態 | 見せ方 |
|---|---|
| 読み込み中 | 中身の位置に順に灯る点（`.k-loader`）と「読み込み中」（13px の `muted`、`role="status"`）。欄に `aria-busy="true"` |
| 取得の失敗 | 中身を出さず、ALERT の知らせの欄（`role="alert"`）だけ。何をすればいいかまで書く |
| 更新の失敗 | 前の中身を残し、その上に ALERT の知らせの欄を足す。いつの時点の中身かを書く |
| 空 | 枠なしの小さい空の表示（`.k-empty--sm`: 余白 24px 16px、ソリッドのアイコン 32px、13px の文、ボタンなし） |

- 読み込み中・失敗を空の表示で代用しない

## 🧺 分類の色のマスの行（`.k-cellrow`）

行の左に、分類のアイコンと番号を入れたマスを置き、そのマスだけを分類の色で塗る。行ごとの分類をひと目で見分けたい一覧に使う。

| 項目 | 色のある行 | 色の無い行 |
|---|---|---|
| マスの地 | `--extra-text`（分類の色を反転） | 塗らない。マスの右に `border` の線 |
| マスの文字とアイコン | `--extra-bg` | `text` |
| 行の枠 | `--extra-border` | `border-strong` |
| 右の本文 | 塗らない（`surface`） | 塗らない（`surface`） |

- 行の要素に `data-extra-color` を付ける。マスと枠は `var(--extra-text, …)` のように、色が無いときの値を添えて書く（色の無い行も同じ CSS で済む）
- マスの地と文字は、分類の色の文字と地を入れ替えた組なので、比は `tools/build.py` が確かめている 4.5 以上のまま
- マスは行の高さいっぱい（`align-self: stretch`）、余白 0 12px、等幅 13px・太さ 600、アイコン 16px。行の左の角に合わせて左だけ丸める（5px）
- 題名は 14px・太さ 500 で 1 行に省略し、全文を `title` に入れる。下に分類のタグ（`.k-tag` に同じ `data-extra-color`）と分類の名前を文字で出す（色だけに頼らない）
- 行は高さ 44px 以上、角 6px、行どうしの間 4px
- 除外した行を戻して見せるときは、枠を点線、文字を `muted`、マスを塗らずに点線の区切りにする（`.is-excluded`。透明度で薄めない）

## 📆 期日の印（`.k-due`）

期日は、アイコンと日付・残りの日数の 2 段で出す。

| 状態 | 色 | アイコン（16px） | 1 段目 | 2 段目 |
|---|---|---|---|---|
| 超過 | `.k-role-alert`、太さ 600 | `warning-octagon` | `11-24` | 2 日超過 |
| 今日 | `.k-role-warning`、太さ 600 | `warning` | `11-26` | 今日 |
| まだ先 | `muted` | `calendar` | `12-03` | あと 7 日 |
| 期日なし | `muted` | なし | `—` | なし |

- 1 段目は等幅 13px、2 段目は 12px の日本語。どの行も 2 段の高さにして、列の幅と行の高さをそろえる（`white-space: nowrap`）
- 年が今年でないときだけ `2027-01-08` のように年を付ける
- 色だけに頼らず、2 段目の文字で状態を伝える。アイコンは飾り（`aria-hidden`）
- 「—」は `aria-hidden` にし、読み上げ用に「期日なし」を見えない文字（`.k-visually-hidden`）で添える
- 文字は `base`・`surface` の上に置く（役割の色の文字が 4.5 以上になる地）。分類の色の地の上には置かない
