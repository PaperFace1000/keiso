# 🎨 配色

色の値の正本は `tokens/palette.json`。CSS 変数は `tokens/themes.css`（`tools/build.py` が作る生成物）。見本は `samples/palette.html`。

## 🖥️ 4 つのテーマ

| `data-theme` | 名前 | 種類 | ベース | 文字 | 差し色 | 地の性格 |
|---|---|---|---|---|---|---|
| `shiro` | 白 | ライト | `#F5F5F2` | `#141414` | `#D71921` | 既定。白い地に黒い文字、差し色は信号の赤 |
| `kaki` | カーキ | ライト（中間） | `#DFD9C3` | `#221F19` | `#A63B25` | 生成りがかったカーキの地に焦げ茶の文字。差し色は錆びた赤 |
| `ekisho` | 液晶 | ライト（中間） | `#C4CC9E` | `#0D1806` | `#24401A` | 携帯ゲーム機の古い液晶のような黄緑の地に、深緑の文字 |
| `kuro` | 黒 | ダーク | `#0B0B0B` | `#E8E8E5` | `#E0262D` | ほぼ黒の地に明るい灰の文字。差し色は明るい赤 |

- `<html>` に `data-theme` が無ければ、OS の設定に従う。ライトなら `shiro`、ダークなら `kuro`
- 利用者が選んだテーマは `<html>` の `data-theme` に付ける。選んだものを残すときの決まりは `docs/coding.md`
- `data-theme` は `<html>` 以外の要素にも付けられる（テーマを並べて見せる見本のカードなど）。その要素の中だけがそのテーマの色になる。アプリの画面では `<html>` にだけ付ける
- 中間の 2 つ（カーキ・液晶）は、白では眩しく黒では暗すぎるときのためのもの。どちらもライトとして扱う（`color-scheme: light`）

### 🪜 テーマの作り方

- ベースとサーフェスの明るさの差は小さくし、欄はサーフェス（ライトは一段明るい、ダークは一段明るい）と 1px の枠で浮かせる
- `sunken` はベースより一段沈めた色。なぞったときの行・入力欄の横の補助などに使う
- 役割の色の背景（`-bg`）と枠（`-border`）は、役割の色をベースに混ぜて作る。テーマごとに混ぜる割合を変え、地の色に寄せる
- 液晶は地が緑なので、SUCCESS の緑は地に溶けやすい。名前と印を必ず添え、色の差に頼らない

## 🏷️ トークン

CSS 変数は `--color-<名前>`。

| 名前 | 使いどころ |
|---|---|
| `base` | 画面の地 |
| `surface` | 欄・入力欄・表の見出しの地 |
| `sunken` | なぞった行、一段沈めたところ |
| `border` | 欄の枠、区切り線 |
| `border-strong` | 入力欄・ボタンの枠、四隅の鉤、区切り線の真ん中の四角 |
| `text` | 本文。主な操作のボタンと選んでいる行の地にも使う（反転） |
| `muted` | 補足、ラベル、日時、プレースホルダー |
| `accent` | 差し色。ロゴの印、今いるページの下線、フォーカスの輪 |
| `accent-strong` | 差し色を文字にするとき（リンクを目立たせる、プロンプトの `>`） |
| `on-accent-strong` | `accent-strong` の地に乗せる文字 |
| `success` / `info` / `warning` / `alert` | 状態の文字と印 |
| `-bg` / `-border` | 状態の欄の地と枠（`success-bg` など） |
| `on-alert` | ALERT のボタンの文字 |
| `selection-bg` / `selection-text` | 反転（選んでいる行、文字の選択）。地は `text`、文字は `base` と同じ値 |
| `focus` | フォーカスの輪（`accent` と同じ値） |
| `grid-dot` | 画面の地に敷く点の格子 |

コードの色分けは `--shiki-*`（Shiki の CSS 変数テーマの名前）。キーワードは紫、文字列は SUCCESS、関数は INFO、定数は WARNING、消した行は ALERT の色を使い、どれもサーフェスの上で比 4.5 以上。

## 🚦 役割の色（状態）

| 名前 | 意味 | 例 |
|---|---|---|
| `SUCCESS` | 終わった・うまくいった | 保存した、同期した |
| `INFO` | 知らせるだけ。対応は要らない | 新しい版がある、件数のお知らせ |
| `WARNING` | このままだと困る。見ておいてほしい | 残りが少ない、期限が近い |
| `ALERT` | 失敗した・取り消せない | 保存できなかった、削除の確定 |

- 状態の色は `color`・`-bg`・`-border` の 3 つを組で使う。部品では `.k-role-success` などで `--k-role`・`--k-role-bg`・`--k-role-border` に入れ、部品の側はこの 3 つだけを見る
- **色だけで意味を伝えない。** 四角い点・アイコン・名前（大文字の英語）を必ず並べる
- 差し色（赤）と ALERT（赤）は色が近い。差し色は小さな面積の飾りにだけ使い、意味を持たせない。意味を持たせるのは ALERT の印と名前

## ✒️ 差し色を文字に使うとき

| テーマ | `accent` / `base` の比 | 文字に使ってよいか |
|---|---|---|
| shiro | 4.7 | よい（ただし文字には `accent-strong` を使うのを基本にする） |
| kaki | 4.5 | よい |
| ekisho | 6.8 | よい |
| kuro | 4.2 | **使わない**。文字には `accent-strong`（比 6.4） |

テーマを切り替えても同じ CSS で済むよう、**差し色を文字にするときは常に `--color-accent-strong` を使う**。`--color-accent` は線・点・輪など文字以外に使う。

## 🔁 反転（選んでいる状態）

- 選んでいる行・押している区切りの選択・主な操作のボタンは、地を `text`（`selection-bg`）、文字を `base`（`selection-text`）にする
- 文字の選択（`::selection`）も同じ色にする
- 反転した行の補足の文字は、`muted` ではなく反転の文字の色を少し薄めて使う（`opacity: .75`）

## ⠿ 点の格子

- 画面の地にだけ、16px 間隔・直径 2px の点を `grid-dot` で敷く（`.k-dotgrid`）
- 欄の中・表・入力欄には敷かない。文字の裏に点が来ると読みにくい
- 敷くかどうかは画面ごとに決めてよい。一覧や入力が主役の画面では敷かない

## 🎨 分類の色

分類やタグを色で見分けるための 12 色。正本は `tokens/extra-colors.json`、CSS は `tokens/extra-colors.css`、見本は `samples/extra-colors.html`。

| `data-extra-color` | 名前 |
|---|---|
| `red` | 赤 |
| `orange` | 橙 |
| `ochre` | 黄土 |
| `olive` | オリーブ |
| `green` | 緑 |
| `teal` | 青緑 |
| `cyan` | 水 |
| `blue` | 青 |
| `indigo` | 藍 |
| `violet` | 紫 |
| `magenta` | 赤紫 |
| `gray` | 灰 |

- 要素に `data-extra-color="blue"` を付け、`var(--extra-text)`・`var(--extra-bg)`・`var(--extra-border)` で塗る。値はテーマごとに変わる
- 文字（`--extra-text`）は、どのテーマでもサーフェスと自分の背景（`--extra-bg`）の上で比 4.5 以上
- 状態の色と取り違えないよう、分類の色はタグ（`.k-tag`）や列の小さな印にだけ使い、知らせの欄の色には使わない
- 色の名前を利用者に見せるときは、名前の文字も並べる（色だけで選ばせない）

## 🔍 コントラストの検査

- 文字として使う組み合わせは、4 テーマすべてで比 **4.5 以上**（WCAG AA）
- 検査する組み合わせは `tools/build.py` の `TEXT_PAIRS`（本文・補足・差し色の文字・状態の文字とその背景・反転・ALERT のボタン）、コードの色、分類の色
- 1 つでも下回ると `build.py` は何も書かずに止まる。値を直してからやり直すこと
- 枠・点・フォーカスの輪のような文字でないものは、比 3 を目安にする（検査はしていない）。`samples/palette.html` が今のテーマの比を計算して出す
