# 🧱 画面の組み立て

見本は `samples/patterns.html`。浮かぶ部品とダイアログは `samples/overlays.html`、欄と一覧は `samples/records.html`、日付と時刻は `samples/time.html`。部品そのものの決まりは `docs/components.md`、寸法は `docs/layout.md`。

## 🧢 ヘッダー（`.k-header`）

- 画面の上に固定する（`position: sticky; top: env(safe-area-inset-top, 0px)`）。高さ 52px 以上、地は `base`、下に 1px の `border`
- 左にロゴ（トップへのリンク）、続けて主なページのリンク（`.k-nav`）、右端に操作（テーマ・ユーザーのメニュー）
- ナビの文字は等幅 12px・大文字・字間 `0.12em`、色は `muted`。今いるページは `text` にして、下に 2px の `accent` の線を引き、`aria-current="page"` を付ける
- ナビには `aria-label` で名前を付ける（`aria-label="主なページ"`）
- 幅が足りないときはナビを次の行に回す（`flex-wrap: wrap`）。599px 以下ではアイコンだけにしてもよい。その場合も `aria-label` を残す

## 🗂️ タブ（`.k-tabs`）

- 等幅 12px・大文字の文字を 16px 空けて並べ、下に 1px の線
- 選んでいるタブは `text` にして、下に 2px の `text` の線（ヘッダーと違い差し色を使わない）
- 横に並びきらないときは、タブの帯の中だけ横にスクロールさせる
- 役割は `role="tablist"`・`role="tab"`・`aria-selected`。←→ のキーで移れるようにする

## 🪟 ダイアログ（`.k-dialog`）

- `<dialog>` で作る。幅は `min(32rem, 100vw - 32px)`、枠は `border-strong`、地は `surface`、角なし
- 頭（線のアイコン + 見出し 16px + 閉じるボタン）・本文（14px）・足（ボタンを右寄せ、地は `base`）の 3 段。段の間は 1px の線
- 後ろの幕は黒の 45% の透明度
- **外側のクリックで閉じない。** 閉じるのは閉じるボタン・キャンセル・Esc だけ（入力の途中の内容を守る）
- 取り消せない操作の確認は、ALERT のボタンで確定させ、何が消えるかを本文に具体的に書く
- 開いたらフォーカスを中に移し、閉じたら開いたボタンに戻す
- 幅は 3 つ。普通（`min(32rem, 100vw - 32px)`）、広い版（`.k-dialog--wide`、`min(55rem, 100vw - 32px)`。詳細や本文を並べて見るもの）、選ぶダイアログ（`.k-dialog--picker`、下の「項目を選ぶダイアログ」）
- 中身が画面より高いときは本文だけをスクロールさせ、足のボタンまで届くようにする（`max-height: calc(100dvh - 32px)`）

## 📢 知らせの出し方

| 何を知らせるか | 部品 |
|---|---|
| 操作の結果（保存した・送った） | トースト。SUCCESS の印 |
| 画面全体に関わる状態（同期できていない・版が古い） | ページの上の知らせの欄 |
| その欄の失敗（読み込めなかった・保存できなかった） | その欄の中の ALERT の知らせ。中身は消さずに残す |
| 入力の誤り | 欄の下の ALERT の文字（`docs/components.md` の入力欄） |

- 1 つの出来事を 2 か所で知らせない（トーストと欄の両方に出さない）

## ⏳ 読み込み中と空の表示

- 読み込みに 0.5 秒以上かかるところだけ、順に灯る点（`.k-loader`）と文字を出す
- 読み込めたが中身が無いときは空の表示（`.k-empty`）。何も無い理由と次の操作を書く
- 読み込みに失敗したときは空の表示を出さず、ALERT の知らせとやり直すボタンを出す

## 📨 二重送信を防ぐ

- **サーバー側で防ぐのが本筋。** 作成する処理は、同じ要求を 2 回受けても 1 件しか作らない（要求ごとの一意なキー、内容のハッシュ、一意の制約など）
- 画面側は補助として、送信している間はボタンを押せなくし、`aria-busy="true"` を付ける（点滅する四角いカーソルが出る）
- 押された瞬間に同期的に止める印を持つ。画面の状態の更新を待つと、連打の 2 回目をすり抜ける
- ページを移る通常の送信も、送信したらボタンを押せなくする
- 失敗したら押せる状態に戻し、ALERT の知らせを出す
- 送信する操作を足したら、E2E のテストに「連打しても 1 件しか作られない」確かめを入れる

## 🔢 結論を先に出す画面

- 一番言いたい数字は、画面の最初に数字の欄（`.k-stat`）で大きく出す。詳しい表はその下
- 数字には単位・期間・比べる相手を添える
- 数字の欄は 2〜4 個を横に並べる。5 個以上にしない（どれが結論か分からなくなる）

## 📊 図

見本は `samples/layout.html` のダッシュボード。図の色はテーマの変数だけを使う。

- 図の種類は中身で選ぶ。推移は折れ線、項目どうしの比べ合いは横棒、**割合・内訳はドーナツ**
- **ドーナツは塗りの太い輪にせず、点を円周に並べて描く。** 点 1 つを 1 件（件数が多いときは 1〜2%）にし、項目の境目は 1 点分空ける。点は隙間が見える大きさにし、くっついて線に見えないようにする
- 輪の内側には目盛りの代わりに細い点線の輪を置き、真ん中に結論の割合をドットの書体で出す
- 凡例は丸い点・名前・件数と割合を 1 行に並べ、件数と割合は等幅で右にそろえる
- 折れ線は 2px の線と白抜きの点、最後の点だけを差し色で塗って値を添える。比べる相手（前期など）は点線にする

## 📋 一覧と詳しい画面

- 一覧の行を選ぶと、行が反転して右（狭い画面では次の画面）に詳しい中身を出す
- 詳しい中身の上には値の一覧（`.k-kv`）で要点を出し、本文はその下
- 一覧の上に件数（`.k-count`）と絞り込み・並べ替えを置く

## ⌨️ キーボードで動かす

- よく使う操作にはキーを割り当て、ボタンの横か説明に `kbd` で示す
- 検索・コマンドの欄（プロンプト）は `/` か `Ctrl` + `K` で開けるようにする
- 一覧は ↑↓ で行を移れるようにし、Enter で開く

## 🏷️ 項目を選ぶダイアログ（`.k-dialog--picker`）

候補が多い、検索がある、固定した候補があるなど、欄の下のポップオーバーでは窮屈な選択に使う。大きく重なって後ろが隠れるので、**何を選んでいるのか**と**今の値**をダイアログの中に出す。

| 項目 | 値 |
|---|---|
| 位置 | 上に寄せる（上から `max(16px, 6vh)`、左右の中央）。検索で一覧の高さが変わっても見出しが動かない |
| 幅・高さ | 900px 以上は `min(72rem, 100vw - 32px)`・高さ `min(52rem, 画面に収まる最大)`。それより狭いと `min(44rem, 100vw - 32px)`・画面の高さいっぱい。高さを決めておき、一覧の数で枠を伸び縮みさせない |
| 左右の 2 段 | 900px 以上では左に固定した候補（1fr）、右に探す欄と残りの一覧（1.25fr）。間に `border` の縦線と 16px。それぞれの段の中でスクロールする |
| 見出し | 線のアイコンと「何の値を選ぶのか」（「この記録を付ける棚」）。右に閉じるボタン |
| 説明 | 見出しの下に 13px の `muted` で、選んでいる対象。3 行で切る |
| 今の値 | 地 `sunken`・角 4px・余白 8px 12px の帯。左に `.k-label` の `CURRENT`、右に今の値（無ければ「なし」を `muted`） |

- 並びは上から: 見出し → 説明 → 今の値 → 固定した候補 → 探す欄 → 「なし」→ `RECENT` → 分類ごとの一覧
- 行は `.k-option`。今の値の行は右端に四角い点、なぞった行は反転。長い名前は省略せず折り返す
- 「なし」は一覧の行にせず、アイコン付きの小さいボタンにする（押せることが分かるように）
- 選ぶだけで、消えて困る入力が無いので、**外側を押しても Esc でも閉じてよい**（普通のダイアログの「外側で閉じない」の例外）。閉じたら開いたボタンにフォーカスを戻す
- 599px 以下では外の余白を 8px、本文の余白を 12px に詰める
- 段の中のフォーカスの輪が欠けないよう、スクロールする段の内側に 4px の余白を取る

## 🪪 詳細のダイアログ

一覧の番号か題名を押すと、その項目の詳細を広い版のダイアログで開く。

- 上から: 見出し（線のアイコン + 題名の全文。省略せず `overflow-wrap: anywhere`）→ 分類のタグと状態の印 → 値の一覧（`.k-kv`）→ 本文 → 足のボタン
- 本文は `white-space: pre-wrap` の文字として出す。利用者の書いた HTML をそのまま描かない。URL をリンクにするときは `http:`・`https:` だけ
- 足: 左に関連するリンク（括弧のボタン・`link`）、右に「元のページで開く」（`arrow-square-out`、`target="_blank"` と `rel="noopener noreferrer"`）と「閉じる」（主）
- 関連するリンクにするのは、https で、設定で決めたホストに完全に一致するものだけにする（部分一致にしない）
- 外側のクリックでは閉じない。閉じるのは「閉じる」のボタン・閉じるアイコン・Esc
- 読み込み中は本文の位置に順に灯る点と「読み込み中」、失敗は本文の位置に ALERT の知らせの欄。値の一覧は一覧で分かっている値を先に出してよい

## 🔄 ヘッダーの状態の小ボタン（`.k-statusbtn`）

同期などの状態をヘッダーに小さく出し、押すと詳しい中身をポップオーバーで出す。

| 項目 | 値 |
|---|---|
| ボタン | 高さ 28px、余白 0 8px、枠は透明。7px の四角い点と、等幅 11px・大文字の短い名前（`SYNC 09:12`）。色は `.k-role-*` |
| なぞる・開いている | 地 `sunken`、枠 `border` |
| 失敗のとき | `.k-role-alert` で `SYNC FAILED` |
| ポップオーバー | 幅 `min(360px, 100vw - 16px)`、ボタンの右端にそろえて下に開く |
| 中身 | 見出し（`.k-label`）と、つなぎ先ごとの箱（地 `base`、枠 `border`、角 4px、余白 8px 12px）に名前（太さ 600）・最後に成功した日時（等幅 12px の `muted`）・失敗の理由（12px の `alert`）、右に「今すぐ更新」（小さいボタン） |

- 599px 以下では名前を隠して点だけにする。`aria-label` に状態の文を全部入れる（「同期の状態（同期 09:12）」）
- 「今すぐ更新」は送信と同じく、押したら終わるまで押せなくする（`aria-busy`）。結果は箱の下に 1 行で出し、失敗は `role="alert"`
- 出す意味がない（設定が無い）ときはボタンごと出さない

## 🎛️ 見出しから開くフィルタのポップオーバー

一覧の見出しの「フィルタ」から、絞り込みの条件をその場で確かめ・変える。

- 見出しの右に括弧のボタン「フィルタ」（`sliders-horizontal`）。効いている条件があれば件数（`.k-count`）を添える。0 件なら件数を出さない
- ポップオーバーは幅 `min(22rem, 100vw - 32px)`、ボタンの右端にそろえて開く
- 中身は、条件 1 つにつき 1 行: 効かせるかのチェックボックス・条件の文（「題名に「いつか」を含む」）・削除のボタン（`trash`、`aria-label="「いつか」のフィルタを削除"`）。下に足す欄（36px）と「追加」
- **変えたらすぐ一覧に反映する**（保存のボタンを置かない）。件数も同時に変え、`aria-live="polite"` で読み上げる
- 削除は確認しない（同じ条件を入れればすぐ戻せるため）
- 開いたら足す欄にフォーカス。閉じるのは外側を押す・Esc・ボタンをもう一度押す
- 保存先を持つアプリでは、条件の変更はサーバーに保存し、二重送信を防ぐ

## 👀 除外の切り替え

フィルタで外した行を、今だけ一覧に戻して確かめる。

- 見出しの右（フィルタのボタンの左）に、括弧の小さいボタン「フィルタで 3 件を除外」（`funnel`）を置く。押すと反転し（`aria-pressed="true"`）、文言を「除外した 3 件を隠す」（`eye-slash`）に替える
- 除外した行が無いときはボタンを出さない
- 戻した行は、枠を点線、文字を `muted` にする（`.k-cellrow.is-excluded`）。`opacity` で薄めない（文字の比が 4.5 を割るため）。2 段目に「除外: 「いつか」を含む」と、どの条件で外れたかを書く
- 見出しの件数は、除外した後の件数のままにする
- 切り替えたことは `aria-live="polite"` で読み上げる（「除外した 2 件を表示しています」）
- **覚えさせない**。再読み込み・ページを移ったら除外した状態に戻す

## 🧮 列をそろえる一覧（`.k-gridlist`）

一覧の行を表のように並べ、番号・題名・期日・時間・操作の列の幅を行の間でそろえる。

```css
.k-gridlist { display: grid; grid-template-columns: auto minmax(0, 1fr) auto auto auto; row-gap: 4px; }
.k-gridlist > li { display: grid; grid-column: 1 / -1; grid-template-columns: subgrid; }
.k-gridlist .k-cellrow { grid-column: 1 / -1; display: grid; grid-template-columns: subgrid; column-gap: 12px; }
```

- 列は一覧が決め、行は `subgrid` でその列を共有する。行ごとの flex では期日や時間の幅が行で変わり、縦の線がそろわない
- 題名の列だけ `minmax(0, 1fr)`（1 行で省略）、ほかは `auto`（一番広い行に合わせる）
- 操作の列は列の幅いっぱいにし、ボタンを右に寄せる（`justify-self: stretch; justify-content: flex-end`）
- 行の見た目は分類の色のマスの行（`docs/components.md`）。期日は期日の印、時間は等幅の右寄せ
- **599px 以下ではカードに崩す**: 一覧を 1 列にし、行の中を「マス（2 段の高さいっぱい）／1 段目に題名／2 段目に期日・時間・操作」に並べ替える。横にはみ出させない
- 行は `<li>` のまま（`role="table"` にしない）。列の見出しは出さない

## ⭐ 上へ・下へで並べ替えるカードの一覧

よく使う項目を利用者が選んで置き、並び順も決める。

- 欄（`.k-section`）に入れる。見出しに `star` と件数。置くのは各一覧の行のピン（`docs/components.md`）から
- カードは分類の色のマスの行。左からマス → 題名と分類 → 「上へ」「下へ」（アイコンだけの小さいボタン、`arrow-up`・`arrow-down`、間 2px）。`aria-label` は「（題名）を上へ」
- 先頭の「上へ」と末尾の「下へ」は押せない形（斜線と点線の枠）にするが、`disabled` ではなく `aria-disabled="true"` にし、押しても何もしない（`disabled` にすると、端まで動かしたときにフォーカスが外れるため）
- **押したあともフォーカスを同じボタンに残す**。DOM を直に動かすときは、押した行ではなく隣の行の方を動かす
- 動かしたら `aria-live="polite"` で「（題名）を 2 番目に動かしました」と読み上げる
- 並び順は動かすたびに保存する。送るのは「1 つ上へ」の操作ではなく、並べ終えた ID の列（同じ要求が 2 回届いても結果が同じ）
- 空のときは欄の中の小さい空の表示（`solid:star`）で、置き方を書く
- 10 件を超えるならドラッグでも動かせる作りにし、「上へ」「下へ」は行のメニューに入れる

## 🎯 目標に対する横棒（`.k-goal`）

分類ごとの合計を目標と比べる。進み具合の目盛り（`.k-meter`）とは別の部品にする。

| 項目 | 値 |
|---|---|
| 1 行 | 1 段目に分類のタグ・「合計 12:30 / 目標 20:00」（等幅）・右端に「残り 7:30」か「0:30 超過」（12px）。2 段目に棒 |
| 棒 | 高さ 8px、角 1px の四角。下地は `border`、中身は分類の色（`--extra-text`。色が無ければ `muted`） |
| 目標を超えたとき | 棒の全体を合計にし、目標までを塗り、超えた分を同じ色の斜めの縞（2px の線と 3px の隙間）にする。目標の位置に、棒の上下へ 4px ずつはみ出す `text` の 2px の縦線。「超過」の文字は `alert`・太さ 600 |
| 目標の内側 | 目標の位置（右端）に同じ縦線。「残り」は `muted` |
| 目標の無い分類 | 「合計 1:45」と「目標なし」だけ。棒は出さない |

- 超えた量・残りは必ず文字で出す（縞だけに頼らない）。棒は飾りなので `aria-hidden`
- 超えた分を別の色にしない（分類の色と混ざるため）
- 並びは目標のある分類を先、その中で合計の多い順

## 📋 値の一覧とコピー（`.k-copylist`）

作った値（番号・ランダムな文字列など）を並べ、1 つずつかまとめてコピーする。

- `<ol>` に `aria-label`。行の間 4px。1 行は地 `surface`、枠 `border`、角 4px、余白 4px 4px 4px 12px。左に 2 桁の番号（等幅 11px の `muted`）、値（等幅 13.5px、`overflow-wrap: anywhere`）、右にコピーのボタン
- コピーのボタン（`.k-copy`）: 括弧の小さいボタンに `copy` 14px と「コピー」（12px の `muted`）。押すと 1.5 秒だけ「コピーした」（`check`、`success`）か「コピーできなかった」（`warning`、`alert`）に替える。文言は `aria-live="polite"`
- 行ごとのボタンは `aria-label` を「n 行目をコピー」にする（長い値をそのまま読み上げないため）
- 「作る」（主・小さいボタン、`arrow-clockwise`）の右に「すべてコピー」。改行でつないでコピーする。値が 2 件以上のときだけ出す
- 同じ値が並ぶこともあるので、行は位置で区別する

## 🧾 コマンドの早見表（`.k-cheats`）

コマンドと説明・例を並べた早見表。

- 一覧: `<ul>` を地 `surface`・枠 `border`・角 6px で囲み、行の間に `border` の線。1 行は余白 10px 12px の 2 列（`minmax(0, 2fr) minmax(0, 3fr)`、間 4px 16px）。599px 以下で 1 列に積む
- 左: コマンド（等幅 13.5px）と、横にコピーのボタン（値の一覧と同じ）。`aria-label` は「rec をコピー」（短いので値を入れる）。2 文字以下のコマンドにはボタンを付けない
- 右: 説明（14px）と、その下に例（13px の `muted`）
- 説明の中のコードは `.k-code-inline`（等幅 0.92em、余白 0 4px、角 3px、地 `sunken`）
- **置き換えの例**: 「前」は `alert-bg` の地に `alert` の文字と取り消し線、「後」は `success-bg` の地に `success` の文字、間に `arrow-right`。頭に見えない文字で「前: 」「後: 」を添える
- **探す例**: パターン → `arrow-right` → 文章。一致した部分は `<mark>` に `warning-bg` の地と下に `warning` の 2px の線、文字は `text`
- **大きく見せるコマンドのカード**: 見出し 15px、コマンド（等幅 20px、地 `sunken`、角 4px）とコピーのボタン、補足（13px の `muted`）
- **注意の囲み**: 節の頭に、地 `warning-bg`・枠 `warning-border`・角 6px・余白 10px 16px の箱。知らせの欄より軽い、読み物の中の注意に使う

## ⏩ 日付の送り（`.k-periodbar`）

1 日・1 か月ずつ見る画面の上の帯。月のカレンダーの上の帯も同じ作りにする。

- 左に見出し（等幅 18px・太さ 700。日なら `2026-11-26 THU`、月なら `2026 年 11 月`）と、その横に補足（13px の `muted`。「今日」「3 日前」や和暦の年）
- 右に「前の日」（括弧なしのアイコンだけのボタン、`caret-left`、`aria-label`）・「今日」（小さいボタン）・「次の日」（`caret-right`）
- 今日を見ているときは「今日」を押せない形（`aria-disabled`）にする
- 見出しは `aria-live="polite"` にし、移ったことを読み上げる
- 幅が足りなければ、ボタンの組を次の行に回す
- 見ている日・月は、残す意味があれば URL に残す（`?day=2026-11-26`・`?month=2026-11`）

## 🗓️ 月のカレンダー（`.k-cal`）

| 項目 | 値 |
|---|---|
| 並び | 日曜から始まる 7 列の `table`（`table-layout: fixed`、`border-collapse: separate`、`border-spacing: 2px`） |
| 曜日の見出し | 等幅 11px・大文字の英語（`SUN`）を `<abbr title="日曜">` で。`scope="col"` |
| 日のマス | 地 `surface`、枠 `border`、角 4px、余白 4px 6px、高さ 4.25rem、上寄せ |
| 日の数字 | 等幅 14px、26px の四角の中 |
| 土曜・日曜 | マスの地を `sunken` に沈める |
| 日曜・祝日 | 数字を `muted` にする |
| 祝日 | 地を `sunken`、数字を `muted`。数字の下に 5px の四角い印と名前（11px の `muted`）。名前は `title` にも入れる |
| 今日 | 数字を反転（地 `text`、文字 `base`、角 3px）。マスに `aria-current="date"` |
| 前後の月の日 | 地を塗らず、枠を点線、数字を `muted` |

- **日曜・祝日を赤くしない。** 赤は ALERT（失敗・取り消せない）の色なので、休みの日に使うと異常に見える。休みの日は地を沈め、数字を薄くし、祝日には印と名前を添えて区別する
- 色だけに頼らない: 曜日は列の見出しの文字で、祝日はマスの中の名前で分かるようにする
- 上の帯は日付の送り（`.k-periodbar`）と同じ作り。見出しの横に和暦の年を 13px の `muted` で出す
- 和暦の年は `Intl.DateTimeFormat('ja-JP-u-ca-japanese', { era: 'long', year: 'numeric' })` の `formatToParts` で取り、年が「1」なら「元年」にする。月の初日と末日で元号が違えば「平成31年／令和元年」と並べる
- **599px 以下**: マスの高さを 2.75rem、余白 2px にして数字を真ん中に置き、祝日の名前を隠す。祝日は数字の下の 2px の線（`muted`）と下の一覧で伝える
- **その年の祝日の一覧**: カレンダーの下に見出し「2026 年（令和8年）の祝日」（16px）と、`repeat(auto-fill, minmax(min(100%, 15rem), 1fr))` の一覧。1 行は「05/03（日）」（等幅）と名前、下に `border` の線。過ぎた日は `muted`、今日の行は太字で `aria-current="date"`
- 祝日のデータが無い年は、一覧の位置にその旨を 13px の `muted` で出す
- 表には見出しとの `aria-labelledby` で名前（「2026 年 11 月」）を付ける

## 🕒 時刻つきのタイムライン（`.k-timeline`）

短い記録を時刻の順に並べる一覧と、その上の書く欄。

| 項目 | 値 |
|---|---|
| 一覧 | `<ol>` に `aria-label`。行の間は空けず、各行の余白 8px 0 |
| 1 行 | `grid-template-columns: 5ch minmax(0, 1fr) auto`、間 0 16px、上寄せ。左から時刻・本文・操作 |
| 時刻 | `<time datetime="2026-11-26T09:15">09:15</time>`。等幅 13px の `muted` |
| 縦の線 | 時刻の右に `border-strong` の 1px。行の `::after` で行の上から下まで引く |
| 点 | 7px の**四角**（角 1px）を `text` で塗り、`box-shadow: 0 0 0 2px var(--color-base)` で地の色のふちを付ける（線が点で切れて見える）。行の `::before` |
| 本文 | 14px・行間 1.7、`overflow-wrap: anywhere` |
| 操作 | 右端に「編集」（`pencil-simple`）・「削除」（`trash`）。アイコンだけの括弧なしの小さいボタン、間 2px |

- 線の端: 先頭の行は点から始め、末尾の行は点で終える。1 件だけなら点だけになる
- 操作のボタンの `aria-label` に時刻を入れる（「09:15 の記録を編集」）
- **書く欄**: 一覧の上に、3 行の複数行の欄と、その下の 1 行（補足 12px の `muted`・右に「記録」の主の小さいボタン、`plus`）。空（空白だけ）の間は押せない。<kbd>Ctrl</kbd>（mac は <kbd>Cmd</kbd>）+ <kbd>Enter</kbd> でも送る。送ったら欄を空にし、フォーカスを欄に戻す。二重送信は「二重送信を防ぐ」のとおり
- **編集はその場で**（ダイアログにしない）: 本文の位置を複数行の欄に替え、下に `TIME` のラベルと `datetime-local`（高さ 28px）、右寄せで「やめる」と「保存」（主、`floppy-disk`）。編集中はその行の操作のボタンを隠す。開いたら欄に、閉じたら「編集」のボタンにフォーカスを移す
  - 本文を空にして保存しようとしたら、保存せずに「本文を入れてください（消すときは削除のボタンを使ってください）」を `role="alert"` で出す
  - 時刻を変えたら一覧を並べ直す
  - Esc を使うエディタ（キー操作を入れ替えるものなど）を置くことがあるので、編集の欄はダイアログに入れない
- **削除**は確認のダイアログ（`role="alertdialog"`）で「09:15 の記録を削除しますか」と聞き、「やめる」と「削除する」（ALERT）。開いたら「やめる」にフォーカス。消したら `aria-live="polite"` で読み上げ、フォーカスを書く欄に移す
- 空のときは一覧の位置に 13px の `muted` で「まだ記録はありません」
- 360px の幅でも時刻の列は 5ch のまま、本文だけ折り返す
