# 🧱 画面の組み立て

見本は `samples/patterns.html`。ヘッダー・パンくず・サイドバー・ツリー・タブ・目次・検索は `samples/navigation.html`、浮かぶ部品とダイアログは `samples/overlays.html`、欄と一覧は `samples/records.html`、日付と時刻と年表は `samples/time.html`、作業の画面は `samples/workspace.html`、会話・浮かぶパネル・まとめた操作・録音は `samples/assist.html`、縦のタブ・動いている処理の札・簡易な絞り込みは `samples/marks.html`。部品そのものの決まりは `docs/components.md`、寸法は `docs/layout.md`。

## 🧢 ヘッダー（`.k-header`）

- 画面の上に固定する（`position: sticky; top: env(safe-area-inset-top, 0px)`）。高さ 52px 以上、地は `base`、下に 1px の `border`
- 左にロゴ（トップへのリンク）、続けて主なページのリンク（`.k-nav`）、右端に操作（テーマ・ユーザーのメニュー）
- ナビの文字は等幅 12px・大文字・字間 `0.12em`、色は `muted`。今いるページは `text` にして、下に 2px の `accent` の線を引き、`aria-current="page"` を付ける
- ナビには `aria-label` で名前を付ける（`aria-label="主なページ"`）
- 幅が足りないときはナビを次の行に回す（`flex-wrap: wrap`）
- **599px 以下ではアイコンだけにする**（`.k-nav--icons`）: リンクと右の操作に線のアイコン 16px を添えておき、文言（`.k-nav__text`）を隠す。各リンクに `aria-label` と `title` を残す
- **リンクが入りきらないとき**は、右の操作に重ねない。リンクの並びだけを横にスクロールさせる（`overflow-x: auto`、スクロールバーは隠す、`min-width: 0`）。並びの上下に 4px の余白を取り、リンクのフォーカスの輪は内側（`-2px`）に出して切れないようにする。右の操作は縮めない（`flex: none`）

## 🍞 パンくず（`.k-crumbs`）

今のページが、どの階層のどこかを示す。本文の先頭、ページの見出しの上に置く。見本は `samples/navigation.html`。

| 項目 | 値 |
|---|---|
| 並び | 13px、項目の間 4px、折り返す（横に送らない） |
| リンク | `accent-strong`、下線はなぞったときだけ |
| 今いるページ | `text`・太さ 600。リンクにしない |
| 区切り | 右向きの矢印を線（`muted`）で描く。文字の `/` や `>` は使わない |
| 先頭 | ホームは文字に `house` 14px を添える |

- `nav` に `aria-label="パンくず"`、`ol` で並べ、今いるページに `aria-current="page"`。区切りは飾りなので読み上げない
- 長い題名は 1 行で省略し、`title` に全文を入れる
- 4 階層を超えるときは、間を `…`（`muted`、`title` にまとめた名前）にまとめて先頭と末尾の 2 つずつを残す
- 1 階層目（ホームの直下）でも出す。出したり消したりすると本文の位置が動く

## 🗂️ タブ（`.k-tabs`）

- 等幅 12px・大文字の文字を 16px 空けて並べ、下に 1px の線
- 選んでいるタブは `text` にして、下に 2px の `text` の線（ヘッダーと違い差し色を使わない）
- 横に並びきらないときは、タブの帯の中だけ横にスクロールさせ、選んだタブを見える位置まで送る。フォーカスの輪は帯の中で欠けないよう内側（`-2px`）に出す
- 先頭にアイコン 16px を置いてよい（文字との間 6px）。件数は名前の右に `.k-count`
- **小さいタブ**（`.k-tabs--sm`）: 横の欄の中の切り替え。11px、余白 8px 0、タブの間 12px、帯の左右 8px。帯を入れ物（`container-type: inline-size`）にし、帯の幅が 480px 以下ならアイコンを外す（`@container`）
- 役割は `role="tablist"`・`role="tab"`（`aria-selected`・`aria-controls`）・`role="tabpanel"`（`aria-labelledby`・`tabindex="0"`）。←→ で移り（端で反対の端へ）、Home・End で端へ。選んだタブだけ `tabindex="0"`、ほかは `-1`（Tab では選んだタブとパネルにだけ止まる）
- 選んだタブは、残す意味があれば URL に残す（`?tab=history`、`history.replaceState`）。読み込み直し・戻るでも同じタブを開く
- パネルの中身の読み込み中は、パネルの中だけに順に灯る点を出す（ページ全体を隠さない）

## 🗄️ サイドバー・幅のつまみ・引き出し（`.k-shell`）

フォルダやページの一覧を左に置く画面。見本は `samples/navigation.html`。

| 項目 | 値 |
|---|---|
| 幅 | 既定 280px。つまみで 200〜560px（画面の幅の半分まで） |
| 見た目 | 地 `surface`、右に `border` の線、余白 12px 8px 32px。上に `.k-label` の見出し |
| 位置 | ヘッダーの下に固定し（`position: sticky`、高さは画面からヘッダーを引いた分）、中だけ縦にスクロール |

**幅のつまみ**（`.k-resizer`）

- サイドバーの右の線の上に幅 6px の当たり（線の真ん中に来るよう `left: 幅 - 3px`）、`cursor: col-resize`、`touch-action: none`
- 普段は見えず、なぞる・フォーカス・ドラッグ中だけ真ん中に `text` の 2px の線を出す（2 段で切り替える）
- ドラッグ（マウス・指）、←→ で 16px（Shift で 64px）、Home で最小・End で最大、ダブルクリックで 280px に戻す
- `role="separator"`・`aria-orientation="vertical"`・`aria-label`（「記録の一覧の幅」）・`aria-controls`・`aria-valuenow` / `aria-valuemin` / `aria-valuemax`・`tabindex="0"`。`title` に操作の説明
- ドラッグの間は本文の文字が選ばれないようにする（`body` に印を付けて `user-select: none`）
- 幅は `localStorage` に保存し、全ページ・ほかのタブで同じにする（`storage` の出来事で追う）。保存できないときはそのページの中だけ覚える

**引き出し（899px 以下）**

- サイドバーを左から出る引き出しにする。幅 `min(320px, 85vw)`、枠 `border-strong`、`z-index: 15`。影は付けない（後ろの幕で浮かせる）
- 閉じている間は `transform: translateX(-100%)` と `visibility: hidden`（読み上げやフォーカスが入らない）。開け閉めは 0.2 秒を 4 段（`steps(4)`）
- 後ろに幕（黒の 45%、`z-index: 14`）。幕・Esc・ページを選んだときに閉じる。開いたら今のページの行（無ければ最初の行）にフォーカスを移し、閉じたら開け閉めのボタンに戻す
- ヘッダーの左端に開け閉めのボタン（`list` ⇔ `x`）。`aria-expanded`・`aria-controls`、`aria-label` は「〜を開く」⇔「〜を閉じる」
- つまみは出さない。900px 以上に広がったら引き出しを閉じる
- `prefers-reduced-motion: reduce` では動かさない

## 🌳 ツリー（`.k-tree`）

フォルダとページの入れ子の一覧。サイドバーに置く。

| 項目 | 値 |
|---|---|
| 行 | 高さ 32px 以上、余白 4px 8px（左は 8px + 深さ × 14px）、角 4px、14px、行の間 2px。なぞると `sunken` |
| 開いているページ | **反転**（`aria-current="page"`）。アイコンと 1 段目も反転の文字の色にし、1 段目は `opacity: .75` |
| アイコン | 開け閉めの `caret-right` 16px（開くと 90 度回す）、`folder` ⇔ `folder-open`、ページは `file-text`。どれも `muted` |

- ページの名前は 2 段: 1 段目にファイル名（等幅 12px の `muted`）、2 段目に最初の見出し。どちらも 1 行で省略する。見出しが無ければ 1 段だけ
- 矢印の無いページの行は、矢印の分（16px）の空きを入れて名前の位置をそろえる
- フォルダの行の右端に「+」（括弧なしのアイコンだけの小さいボタン、`plus`）。**なぞったときとフォーカスがあるときだけ**出す（`opacity`）。なぞれない端末（`hover: none`）では常に出す。`aria-label` は「〇〇に新しいページを作る」
- フォルダの行は `button` で `aria-expanded`。2 段の行は `aria-label` に両方の名前を入れる
- フォーカスの輪は行の内側（`-2px`）に出す（サイドバーのスクロールで切れないように）

## 🧭 目次（`.k-toc`）

長いページの見出しへのリンクの一覧。`nav` に `aria-label="目次"`。見本は `samples/navigation.html`。

| 画面 | 置き方 | 見た目 |
|---|---|---|
| 広い（1200px 以上） | 本文の右の列（15rem、本文との間 32px）に固定（`position: sticky; top: 72px`）。高すぎれば中だけスクロール | 13px |
| 狭い（1199px 以下） | 本文の上に、**閉じた**箱で置く | 余白 6px 12px（開くと下 12px）、地 `surface`、枠 `border`、角 6px、14px |

- 先頭に「目次」の開け閉めのボタン（13px・太さ 600・`muted`、`caret-right` 16px）。`aria-expanded`、開いているときだけ `aria-controls`
- 一覧は左に `border` の線、線との間 12px、項目の間 6px。見出しの深さ 1 段ごとに 12px 字下げ
- 順番に意味がある章には番号を付ける（`1.`・`2.1`。等幅 11px の `muted`、幅をそろえる）
- 今読んでいる章は `aria-current="location"`。太さ 600 と、一覧の左の線に重ねた差し色の 2px の帯。画面の上（ヘッダーの下）を過ぎた最後の見出しにし、印を動かしてもフォーカスは動かさない
- 広い画面の開け閉めは保存して次も同じにする。狭い画面は毎回閉じた状態から始め、項目を押したら閉じてから見出しへ移る（閉じると本文の位置がずれるため）
- 見出しには `scroll-margin-top`（固定のヘッダーに隠れない）。見出しが無いページでは目次を出さない

## 🔎 検索のダイアログ（`.k-search`）

ページを語で探すダイアログ。見本は `samples/navigation.html`。

| 項目 | 値 |
|---|---|
| 位置 | 上から 10vh、左右の中央（結果の数が変わっても入力欄が動かない） |
| 幅 | `min(40rem, 100vw - 32px)`、高さは 80dvh まで。結果の一覧だけがスクロールする |
| 入力の行 | プロンプト（`>`、16px。iOS で拡大されない大きさ）と右に閉じるボタン。下に `border` の線 |
| 状態の文 | 13px の `muted`、`role="status"`。「3 件」「探しています」（順に灯る点）「上位 5 件（全 9 件）」「「倉庫 C」に合う記録はありません。言葉を短くしてください。」 |
| 結果の行 | 題名（14px・太さ 600）・場所（等幅 12px の `muted`）・抜き出し（13px）の 3 段、角 4px。長いものは折り返す |
| 選んでいる行 | **反転**し、先頭に `▸` を点滅させる |
| 一致した語 | `<mark>`: 地 `warning-bg`、文字 `text`、下に `warning` の 2px の線 |
| 操作の説明 | 下に 12px の `muted` で `kbd`。`aria-hidden`（読み上げには入力欄の役割で伝わる） |

- フォーカスは入力欄に置いたまま、↑↓ で行を動かす（`aria-activedescendant`。入力欄は `role="combobox"`、一覧は `role="listbox"`）。Enter で開き、Esc で閉じる。変換中のキーは検索の操作にしない
- 打つたびに探さず 250ms 待つ。探している間は前の結果を残し、`muted` の文字にして一覧に `aria-busy="true"`（透明度で薄めない）
- 多いときは上位の件数だけ出し、全体の件数を状態の文に書く
- **599px 以下では全画面**（幅 100vw・高さ 100dvh・枠と角なし）にし、操作の説明を隠す
- 外側（幕）を押しても閉じてよい（選ぶだけで、消えて困る入力が無いため。普通のダイアログの例外）。閉じたら開いたボタンにフォーカスを戻す
- 開くキーは `/` か `Ctrl`（mac は `Cmd`）+ `K`。入力欄で打っている間は奪わない
- 結果の文字は利用者の書いたものなので、HTML として描かずに文字として入れ、一致した語だけを `mark` で包む

## 🪟 ダイアログ（`.k-dialog`）

- `<dialog>` で作る。幅は `min(32rem, 100vw - 32px)`、枠は `border-strong`、地は `surface`、角 6px（`--radius`）。影は付けない（後ろの幕で浮かせる）
- 頭（線のアイコン + 見出し 16px + 閉じるボタン）・本文（14px）・足（ボタンを右寄せ、地は `base`）の 3 段。段の間は 1px の線
- 後ろの幕は黒の 45% の透明度
- **外側のクリックで閉じない。** 閉じるのは閉じるボタン・キャンセル・Esc だけ（入力の途中の内容を守る）
- 取り消せない操作の確認は、ALERT のボタンで確定させ、何が消えるかを本文に具体的に書く。役割は `role="alertdialog"`、開いたら「やめる」にフォーカスを置く
- 開いたらフォーカスを中に移し（入力のダイアログは最初の欄）、閉じたら開いたボタンに戻す
- 幅は 4 つ。普通（`min(32rem, 100vw - 32px)`。確認と、入力が 1〜3 項目のもの）、中くらい（`.k-dialog--medium`、`min(40rem, 100vw - 32px)`。開始と終了などの組を 2 列に並べると 32rem では窮屈なもの）、広い版（`.k-dialog--wide`、`min(55rem, 100vw - 32px)`。詳細や本文・版を並べて見るもの）、選ぶダイアログ（`.k-dialog--picker`、下の「項目を選ぶダイアログ」）
- 中くらいの幅でも、入力の項目の数の決まり（3 項目まで。組は 1 項目と数える）は変えない。項目を増やすための幅ではない。599px 以下では組を 1 列にする（`.k-range`）。迷ったら普通の幅にする
- 中身が画面より高いときは**本文だけ**をスクロールさせ、頭と足のボタンはいつも見えるようにする（`max-height: calc(100dvh - 32px)`、開いている間は縦の flex、本文に `overflow-y: auto` と `min-height: 0`）。本文の中にさらにスクロールする枠を作らない。スクロールする本文はキーボードでも動かせるよう `tabindex="0"` と `aria-label` を付ける

### 入力フォームのダイアログ

- 入力が 1〜3 項目のものだけダイアログにする。それより長い入力・ほかの画面を見ながら書くものはページにする（戻る・再読み込みで状況が分かり、閉じて消す事故が無い）
- 本文を `<form>` にし、足の主のボタン（保存）は `form` 属性でその `form` を送る。入力の誤りは欄の下に出し、その欄にフォーカスを戻す。送信中は二重送信を防ぐ
- **取り消しにくい操作（削除）は足の左に離して置く**（`.k-dialog__aside`）。見た目は括弧の小さいボタンで、文字と括弧を `alert` にする（`.k-btn--ghost-alert`）。押したらすぐ消さず、確認のダイアログを重ねる。主のボタンと並べると押し間違えるため
- 保存の結果はダイアログを閉じてからトーストで知らせる。失敗はダイアログを閉じずに、本文の上に ALERT の知らせの欄を出す

## 📢 知らせの出し方

| 何を知らせるか | 部品 |
|---|---|
| 操作の結果（保存した・送った） | トースト。成功・お知らせ・注意の 3 種類 |
| 利用者の操作なしに画面を書き直したこと（ほかの画面で変わったので読み直した） | 画面の上の知らせ（`docs/components.md`） |
| 画面全体に関わる状態（同期できていない・版が古い） | ページの上の知らせの欄 |
| その欄の失敗（読み込めなかった・保存できなかった） | その欄の中の ALERT の知らせ。中身は消さずに残す |
| 入力の誤り | 欄の下の ALERT の文字（`docs/components.md` の入力欄） |

- 1 つの出来事を 2 か所で知らせない（トーストと欄の両方に出さない）

## ⏳ 読み込み中と空の表示

- 読み込みに 0.5 秒以上かかるところだけ、順に灯る点（`.k-loader`）と文字を出す
- 読み込めたが中身が無いときは空の表示（`.k-empty`）。何も無い理由と次の操作を書く
- 読み込みに失敗したときは空の表示を出さず、ALERT の知らせとやり直すボタンを出す

## 📨 二重送信を防ぐ

- **サーバー側で防ぐのが本筋。** 作成する処理は、同じ要求を 2 回受けても 1 件しか作らない（要求ごとの一意なキー、内容のハッシュ、一意の制約など）
- 画面側は補助として、送信している間はボタンを押せなくし、`aria-busy="true"` を付ける（点滅する四角いカーソルが出る）
- 押された瞬間に同期的に止める印を持つ。画面の状態の更新を待つと、連打の 2 回目をすり抜ける
- ページを移る通常の送信も、送信したらボタンを押せなくする
- 失敗したら押せる状態に戻し、ALERT の知らせを出す
- 送信する操作を足したら、E2E のテストに「連打しても 1 件しか作られない」確かめを入れる

## 🔢 結論を先に出す画面

- 一番言いたい数字は、画面の最初に結論の数字（主役版の数字の欄 `.k-stat--lead`、四隅の鉤・72px）で 1 つだけ大きく出す。詳しい表はその下
- 2 番手の数字は普通の数字の欄（`.k-stat`、44px）にする。使い分けは `docs/components.md` の「数字の欄」
- 数字には単位・期間・比べる相手を添える
- 数字の欄は主役と合わせて 2〜4 個。5 個以上にしない（どれが結論か分からなくなる）。多い数字は値の一覧か表にする
- 分類の色の枠や左の帯で数字の欄を塗り分けない（左の帯は状態の印）。分類を見せたいときはラベルの前に分類のベタ塗りの印を置く

## 🃏 カード

行き先を少し大きく並べる。見本は `samples/patterns.html`。

- `grid-template-columns: repeat(auto-fill, minmax(min(100%, 15rem), 1fr))`、間 12px。カードは地 `surface`、枠 `border`、角 6px、余白 16px。影は付けず、なぞると枠を `border-strong` にする。カード全体を 1 つのリンクにする
- 上に区分（`.k-label`）と状態、下の線の下に日付や進み具合
- **行き先が無くなったカード**はリンクにせず、枠を点線・地を透明・文字を `muted`・名前に取り消し線。右上に `[ NOT FOUND ]`（等幅 11px・大文字、`alert`）を置き、本文に「見つかりません」と次にすること（星を外すと消える、など）を書く。全文の場所は `title` に入れる
- 1 件も無いときは、カードの代わりに置き方を 1 行（13px の `muted`）で書く

## 🔑 ログインの画面

- 画面の中央に箱を 1 つ（幅 `min(22rem, 100%)`、四隅の鉤 `.k-frame`、地 `surface`）。上に 48px のソリッドのロゴと `.k-label`
- 並びは上から: ロゴ → **失敗の知らせ**（ALERT の知らせの欄、`role="alert"`）→ ユーザー名 → パスワード → 「次から省く」→ ログイン（主・横いっぱい・`sign-in`）→ 案内
- 失敗の文は、ユーザー名とパスワードのどちらが違うかを言わずに、何をすればいいかまで書く（「ユーザー名かパスワードが違います。大文字と小文字を確かめて、もう一度入れてください。」「試す回数が多すぎます。1 分ほど待ってから試してください。」）。失敗したらパスワードの欄にフォーカスを戻す
- 入力欄に `autocomplete="username"` / `"current-password"` と `required`。最初のフォーカスはユーザー名

## 📊 図

見本は `samples/layout.html` のダッシュボードと「図の枠と色」。図の色はテーマの変数だけを使う。

**図の枠**（`.k-chart`）

| 項目 | 値 |
|---|---|
| 枠 | 地 `surface`、枠 `border`、角 6px、余白 16px |
| 表題 | 15px・太さ 600。**単位と期間を入れる**（「分類ごとの作業の時間（時間・2026 年 11 月）」） |
| 入れ物 | 描く道具に任せる図は**高さだけ**決める（`.k-chart__box`、既定 240px、小さいもの 160px）。図は親の高さに合わせる |
| 凡例 | 四角い点・名前・値（等幅）。系列の名前を必ず文字で出す |
| 注記 | 12px の `muted`。図の下に、読み取り方の補足や合計を書く |

- **図の色は分類の色の文字の色（`--extra-text`）を使う。** 12 色の中でいちばん濃く、どのテーマでも地の上で読める。淡い地の色（`--extra-bg`）を図に渡すと、地に沈んで形が読めない
- 図を描く道具（canvas に描くもの）は CSS 変数をそのまま読めない。**計算後の値を返す小さな関数を 1 つ**作り（見えない要素に `data-extra-color` を付けて `getComputedStyle` で読む）、そこからすべての系列に色を配る
- **テーマが変わったら描き直す。** `data-theme` の変化と `prefers-color-scheme` の変化の両方を見る。文字と目盛りの色は `text`・`muted`、目盛りの線は `border` から取る
- 図だけで意味が通らない数字（合計・割合）は、図の外にも文字で出す。canvas には `role="img"` と要約の `aria-label`

- 図の種類は中身で選ぶ。推移は折れ線、項目どうしの比べ合いは横棒、**割合・内訳はドーナツ**
- **ドーナツは太い輪を項目ごとの弧に分けて描く。** 輪の太さは外側の直径の 1/6 ほど（見本は直径 38 に対して 6）。弧の端は丸めずに四角のまま切り（`stroke-linecap: butt`）、弧と弧の境目は 2px ほど空ける。点を円周に並べる描き方は、割合が読み取りにくいので使わない
- 真ん中に結論（合計や割合）をドットの書体で出す
- 凡例は四角い点・名前・量と割合を 1 行に並べ、量と割合は等幅で右にそろえる
- **1 周は「目安と合計の大きい方」**。目安に満たないときは足りない分を項目の色で塗らず、下地の弧（`border`）にする。超えたら合計を 1 周にし、真ん中に超えた量（`(+1:20)`）を出す。満たないときは真ん中に `/ 8:00`
- 並びは多い順に 12 時から時計回り。「分類なし」「その他」は最後。分類の色は分類の色の `--extra-text`、色の無いものは `muted` を地に混ぜた灰
- **7 件以上**なら、分類のある上位 5 件を残し、残りと「分類なし」を「その他」にまとめる（6 件までは全部出す）。「その他」の凡例の行の `title` にまとめた名前を入れる
- 弧か凡例の行をなぞる・凡例の行にフォーカスする（`tabindex="0"`）と、ほかの分類の弧を `opacity: .25` に、ほかの凡例の行の文字を `muted` にし、その行の地を `sunken` にする。真ん中をその分類の量と「名前・割合」に替え、離れたら合計に戻す（2 段の `steps()`）
- SVG に `role="img"` と全体の要約の `aria-label`（合計・目安との差・各分類の量と割合）。真ん中の文字は `aria-hidden`
- 弧は `<circle pathLength="360">` に `stroke-dasharray`（弧の角度と 360）と `stroke-dashoffset`（始まりの角度の負の値）を付け、`rotate(-90)` で 12 時から始める。角度で書けるので、項目ごとの弧を計算しやすい
- 折れ線は 2px の線と白抜きの点、最後の点だけを差し色で塗って値を添える。比べる相手（前期など）は点線にする

## 🧮 列をそろえる一覧（`.k-gridlist`）

一覧の行を表のように並べ、番号・題名・期日・時間・操作の列の幅を行の間でそろえる。

```css
.k-gridlist { display: grid; grid-template-columns: auto minmax(0, 1fr) auto auto auto; row-gap: 4px; }
.k-gridlist > li { display: grid; grid-column: 1 / -1; grid-template-columns: subgrid; }
.k-gridlist .k-cellrow { grid-column: 1 / -1; display: grid; grid-template-columns: subgrid; column-gap: 12px; }
```

- 列は一覧が決め、行は `subgrid` でその列を共有する。行ごとの flex では期日や時間の幅が行で変わり、縦の線がそろわない
- 題名の列だけ `minmax(0, 1fr)`（1 行で省略）、ほかは `auto`（一番広い行に合わせる）
- 操作の列は列の幅いっぱいにし、ボタンを右に寄せる（`justify-self: stretch; justify-content: flex-end`）
- 行の見た目は分類の色のマスの行（`docs/components.md`）。期日は期日の印、時間は等幅の右寄せ
- **599px 以下ではカードに崩す**: 一覧を 1 列にし、行の中を「マス（2 段の高さいっぱい）／1 段目に題名／2 段目に期日・時間・操作」に並べ替える。横にはみ出させない
- 行は `<li>` のまま（`role="table"` にしない）。列の見出しは出さない

## ⭐ 上へ・下へで並べ替えるカードの一覧

よく使う項目を利用者が選んで置き、並び順も決める。

- 欄（`.k-section`）に入れる。見出しに `star` と件数。置くのは各一覧の行のピン（`docs/components.md`）から
- カードは分類の色のマスの行。左からマス → 題名と分類 → 「上へ」「下へ」（アイコンだけの小さいボタン、`arrow-up`・`arrow-down`、間 2px）。`aria-label` は「（題名）を上へ」
- 先頭の「上へ」と末尾の「下へ」は押せない形（斜線と点線の枠）にするが、`disabled` ではなく `aria-disabled="true"` にし、押しても何もしない（`disabled` にすると、端まで動かしたときにフォーカスが外れるため）
- **押したあともフォーカスを同じボタンに残す**。DOM を直に動かすときは、押した行ではなく隣の行の方を動かす
- 動かしたら `aria-live="polite"` で「（題名）を 2 番目に動かしました」と読み上げる
- 並び順は動かすたびに保存する。送るのは「1 つ上へ」の操作ではなく、並べ終えた ID の列（同じ要求が 2 回届いても結果が同じ）
- 空のときは欄の中の小さい空の表示（`solid:star`）で、置き方を書く
- 10 件を超えるならドラッグでも動かせる作りにし、「上へ」「下へ」は行のメニューに入れる

## 🕒 時刻つきのタイムライン（`.k-timeline`）

短い記録を時刻の順に並べる一覧と、その上の書く欄。

| 項目 | 値 |
|---|---|
| 一覧 | `<ol>` に `aria-label`。行の間は空けず、各行の余白 8px 0 |
| 1 行 | `grid-template-columns: 5ch minmax(0, 1fr) auto`、間 0 16px、上寄せ。左から時刻・本文・操作 |
| 時刻 | `<time datetime="2026-11-26T09:15">09:15</time>`。等幅 13px の `muted` |
| 縦の線 | 時刻の右に `border-strong` の 1px。行の `::after` で行の上から下まで引く |
| 点 | 7px の**四角**（角 1px）を `text` で塗り、`box-shadow: 0 0 0 2px var(--color-base)` で地の色のふちを付ける（線が点で切れて見える）。行の `::before` |
| 本文 | 14px・行間 1.7、`overflow-wrap: anywhere` |
| 操作 | 右端に「編集」（`pencil-simple`）・「削除」（`trash`）。アイコンだけの括弧なしの小さいボタン、間 2px |

- 線の端: 先頭の行は点から始め、末尾の行は点で終える。1 件だけなら点だけになる
- 操作のボタンの `aria-label` に時刻を入れる（「09:15 の記録を編集」）
- **書く欄**: 一覧の上に、3 行の複数行の欄と、その下の 1 行（補足 12px の `muted`・右に「記録」の主の小さいボタン、`plus`）。空（空白だけ）の間は押せない。<kbd>Ctrl</kbd>（mac は <kbd>Cmd</kbd>）+ <kbd>Enter</kbd> でも送る。送ったら欄を空にし、フォーカスを欄に戻す。二重送信は「二重送信を防ぐ」のとおり
- **編集はその場で**（ダイアログにしない）: 本文の位置を複数行の欄に替え、下に `TIME` のラベルと `datetime-local`（高さ 28px）、右寄せで「やめる」と「保存」（主、`floppy-disk`）。編集中はその行の操作のボタンを隠す。開いたら欄に、閉じたら「編集」のボタンにフォーカスを移す
  - 本文を空にして保存しようとしたら、保存せずに「本文を入れてください（消すときは削除のボタンを使ってください）」を `role="alert"` で出す
  - 時刻を変えたら一覧を並べ直す
  - Esc を使うエディタ（キー操作を入れ替えるものなど）を置くことがあるので、編集の欄はダイアログに入れない
- **削除**は確認のダイアログ（`role="alertdialog"`）で「09:15 の記録を削除しますか」と聞き、「やめる」と「削除する」（ALERT）。開いたら「やめる」にフォーカス。消したら `aria-live="polite"` で読み上げ、フォーカスを書く欄に移す
- 空のときは一覧の位置に 13px の `muted` で「まだ記録はありません」
- 360px の幅でも時刻の列は 5ch のまま、本文だけ折り返す

## 🧱 欄の位置と列の幅を変えられるダッシュボード（`.k-board`）

利用者が欄（`.k-section`）の位置・幅と、列の幅を決めるダッシュボード。見本は `samples/workspace.html`。

## 🔍 図・画像を拡大して見る表示（`.k-zoom`）

本文の中の図や画像を、画面いっぱいに広げて見る。見本は `samples/assist.html`。

- **開く所**（`.k-zoomable`）: 図・画像に `role="button"`・`tabindex="0"`・`aria-label`「（名前）（押すと拡大）」、`cursor: zoom-in`。押す・Enter・Space で開く。なぞる・フォーカスで右上（上 6px・右 8px）に「押すと拡大」（12px の `muted`、地 `surface`、枠 `border`、角 4px）。なぞれない端末ではいつも出す
- **ダイアログ**: 普通のダイアログと同じ枠と幕で、画面いっぱい（`100vw - 32px` × `100dvh - 32px`）
- **上の帯**: 余白 8px 10px 8px 16px、下に `border` の線。題名（15px、1 行で省略）→ −・百分率・＋（小さいボタン）・閉じる（括弧なしのアイコンだけ）
- **倍率**: 50・75・100・150・200・300・400%。最初は 100% で、**100% は画面に収まる大きさ**。百分率のボタン（等幅、最小 4.5em）を押すと 100% に戻す。端では −・＋を押せない。`aria-label` は「倍率 200%。押すと画面に合わせる」
- **動かす**: つかんでドラッグで中を送る（pointer capture、`cursor: grab` ⇔ `grabbing`、`touch-action: none`、`user-select: none`）
- **キー**: Esc で閉じる。−・＋（=）で倍率を変える。Tab はダイアログの中を回る
- 外側のクリックでも閉じてよい（入力が無く、すぐ開き直せるため。検索のダイアログと同じ例外）。閉じたら開いた図にフォーカスを戻す
- 図の中に置いた小さな操作（なぞると出るボタン）は、押しても拡大を開かない

## 📦 まとめて実行する操作の下見と結果（`.k-batch`）

いくつもの項目をまとめて送る・移す操作を、下見してから実行する。見本は `samples/assist.html`。

**流れ**: 下見 → 確認 → 実行 → 結果（→ 下見を取り直す）

- **下見**: 「下見する」（普通のボタン、`eye`）で作る。作っている間は順に灯る点と「下見を作っています」（`role="status"`）。区分ごと（作る・変える・消す・飛ばす）に見出し「区分 n 件」（14px）と補足（12px の `muted`）。0 件の区分は出さない
- **行**: 地 `base`、枠 `border`、角 4px、余白 6px 10px。左から状態（6.5rem）・番号と題名（折り返す）・変わる中身（等幅 12px の `muted`、「0:30 → 1:00」）。599px 以下では変わる中身を 2 段目に
- **行の状態**は状態の印: 待ち（`WAITING`、色なしの枠だけの点）・送っている（`SENDING`、INFO の点滅）・済み（`DONE`、SUCCESS）・断られた（`REJECTED`、ALERT）
- **飛ばす項目**: 一覧（13px の `muted`、字下げ 20px）に、理由とどうすれば送れるかを書く（「番号の無い記録 1 件（番号を付けると送れます）」）
- **確認**: 「送る…」を押すと、その場の確認（`.k-confirm`）に件数と、何が書き換わるかを書く。取り消せないもの（置き換えて消すなど）は `role="alertdialog"` の確認のダイアログにする
- **実行中**: すべての操作を押せなくし、行ごとに状態を変える。冪等のキーと下見の ID をサーバーへ送り、下見のときと中身が変わっていたら実行しない（同じ要求が 2 回届いても 1 回分しか動かない）
- **結果**: 全部できたら SUCCESS の知らせの欄（`role="status"`）。一部が断られたら WARNING の知らせの欄に「n 件のうち m 件を送りました。k 件は断られました」と、断られたものの一覧（「#番号: 理由」、13px）。失敗は ALERT の知らせの欄（`role="alert"`）に「もう一度実行すると続きから送ります」
- **反映の状態の小さな表示**（`.k-syncmark`）: 行や見出しの横に、7px の四角い点と 12px の文で「反映済み HH:MM」（SUCCESS）・「未反映」（色なしの枠だけの点）・「失敗」（ALERT）。押すと下見を開く（透明のボタン、余白 2px 6px、角 4px、なぞると `surface`）。反映のあとに中身が変わったら「未反映」に戻す

## 🎙️ 録音のボタン（`.k-rec`）

声を録って送る画面の、一番大きな操作。見本は `samples/assist.html`。

- **大きいボタンを画面の真ん中に 1 つだけ**置く。96px の**四角**（角 6px）、アイコン 36px。影は付けない（浮かぶものではない）
- 待っている間は主のボタン（反転）に `microphone`、録音中は ALERT のボタン（地 `alert`、文字 `on-alert`）に `stop`、保存・送信中は押せなくして順に灯る点（なめらかに回るスピナーは使わない）
- `aria-label` は押すとどうなるかを書き、状態と一緒に替える（「録音を始める」⇔「録音を止めて送る」）
- ボタンの上に経過時間（ドットの数字 56px。1 時間を超えたら `1:02:03`）、その下に今の状態（14px の `muted`、`role="status"`）。経過時間がその画面の結論
- 録音中だけ、経過時間の下に音量の目安（目盛り `.k-meter`、幅 12rem）を動かす。声が届いているかを確かめるため。数字の代わりに `LV` を添え、`aria-hidden`
- 録音中はボタンの下に「取り消す」（括弧のボタン、`x`）を出す。押したら確認のダイアログ（`role="alertdialog"`、「捨てる」は ALERT）を出してから捨てる
- **止めたらすぐ端末に保存し、それから送る。** 送れなかった録音は消さずに「まだ送っていない録音」の一覧に並べ、開き直したときと回線が戻ったときに古い順に送り直す。行ごとに「送り直す」も置く
- 送る要求には端末で作った ID を付け、サーバーは同じ ID を 2 回受けても 1 件しか作らない（再送と連打に備える）
- 送り終えた直後の 1 秒はボタンを押せなくする。停止を 2 回押したとき、2 回目で新しい録音が始まらないようにするため
- 録音中は画面を点けたままにし（Wake Lock）、ページを離れようとしたら止める
