本文

Prose

長い文は幅を 40rem に収め、行間を 1.9 にします。本文の中のリンクだけ下線を残します。箇条書きの印は小さな四角です。

点検の記録の付け方

点検は、見る場所の順番を毎回そろえることが一番の近道です。順番が決まっていれば、見落としに気付きやすく、記録を後から読む人も迷いません。順番は見る場所の一覧にまとめてあります。

  • 温度と湿度は、入口から一番遠い棚で測る
  • 基準の外れは、数字と時刻を両方書く
  • 写真は 1 か所につき 1 枚まで
迷ったら、次の人が読んで同じ場所に立てるかを考えて書く。

記録を付け終えたら、状態を Done にします。直すことが残ったときは Review のまま担当に回します。

コード

Code

色分けは Shiki の CSS 変数（--shiki-*）だけを使います。どのテーマでも、文字の色は背景の上で比 4.5 以上です。上の帯に言語とコピーのボタンを置きます。

TypeScript
// 点検の項目のうち、終わった割合を返す
export function progress_of(items: readonly Item[]): number {
  const done_count = items.filter((item) => item.status === 'done').length;
  return items.length === 0 ? 0 : done_count / items.length;
}
